Taxonomy Extraction Tools

Located under Tools > Extract Taxonomy with Rules..., this dialog provides automated classification tools scoped strictly to cards currently visible in your Master List.

1. Dynamic Entity Harvesting (from Catalog Text)

  • Entity Harvest: Select any canonical card rules attribute and value (e.g. Secondary = Faction or Primary = Region). The app automatically scans active sets in memory, extracts all matching entity titles, and searches your scoped Master List cards for references to those entities.
  • Flavor Text Protection: All Tolkien book quotes and citations (enclosed in quotation marks) are automatically stripped before rules evaluation, preventing lore text from creating false-positive tags.

2. Relational Attribute Lookup (Cross-Card Join)

Enables 2-step relational tagging between linked entities:

  • Source Field: Reads an attribute from cards in scope (e.g. Character Home).
  • Lookup Entity: Matches corresponding cards in the catalog (e.g. Primary = Site).
  • Extract Field: Reads the destination attribute (e.g. Site Region) and writes it into a custom category (e.g. Home Region).
  • Compound Token Parsing: Characters with multiple homesites (e.g. Rivendell, Bree) automatically resolve both sites to generate semicolon-delimited multi-tags (Arthedain; Rhudaur).

3. Custom Regex & JSON Rule Files

Test individual regular expressions in real-time or load batch rule sets from portable .json rule files.
