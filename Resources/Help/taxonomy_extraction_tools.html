Taxonomy Extraction Tools

Located under Tools > Extract Taxonomy with Rules..., this dialog provides automated classification tools scoped strictly to the cards currently visible in your Master List. It allows you to harvest card text, perform cross-card relational joins, or execute regular expressions to tag hundreds of cards in bulk.

Master List Scoping: All extraction tools evaluate only the cards currently visible in the Master List. To target specific cards (e.g. only characters or only cards from a specific expansion), set your filters in the main window before opening the dialog.

Dynamic Entity Harvest (from Catalog Text)

Scans the gameplay text of your scoped cards for references to published entities found across the catalog (such as factions, regions, or characters):

  • Harvest Entity: Select the canonical attribute and value that defines the entities you want to search for (e.g. Secondary = Faction or Primary = Region). The engine inspects all active sets and gathers all published names (e.g. Wood-elves, Riders of Rohan).
  • Save to Category: Enter the custom category name where matched tags will be assigned (e.g. Faction Focus or Recruitable Factions).
  • Flavor Text Protection: All Tolkien book quotes (enclosed in quotation marks) and book citations (e.g. —LotRI) are automatically stripped before evaluation, ensuring lore quotes never generate false-positive tags.

Relational Attribute Lookup (Cross-Card Join)

Performs a two-step relational cross-reference between cards in scope and linked catalog cards to extract attributes into tags:

  • Read Field: The attribute on cards currently in scope used as the join key (e.g. Character Home).
  • Lookup Entity: The catalog criteria used to find matching destination cards (e.g. Primary = Site or Secondary = Faction).
  • Extract Field: The attribute pulled from the matched catalog cards (e.g. Site Region).
  • Save to Category: The custom category where the extracted payload is stored as a tag (e.g. Home Region).
Compound Token Parsing: Characters with multiple locations (e.g. Rivendell, Bree) automatically resolve each site individually to generate clean, semicolon-delimited multi-tags (Arthedain; Rhudaur).

Custom Regex Expression

Evaluates custom .NET regular expressions directly against card rules text:

  • Pattern: The regular expression evaluated against card rules text (e.g. Ruins & Lairs in a Wilderness or \b(greater)\b). Case-insensitivity is enabled by default.
  • Tag Name: The value assigned to matching cards. Supports three formats:
    • Static Value: A single fixed label (e.g. Cancellation).
    • Multi-Tag List: A semicolon-delimited string (e.g. Barad-dûr; Carn Dûm; Cirith Gorgor).
    • Regex Capture Group ($1): If your pattern contains parentheses (...), using $1 dynamically assigns the exact captured word or phrase.
  • Save to Category: The custom taxonomy category where extracted tags will be stored.
Session Persistence: Your last-used Pattern, Tag Name, and Category are automatically remembered across application launches so you can make iterative passes without retyping.

Worked Example: Batch-Tagging Minion Dark-holds

In The Lidless Eye, 15 Minion Orcs, Trolls, and Half-orcs (such as Doeth, Orc Captain, and Troll Lout) have the non-specific home rule Home Site: Any Dark-hold. To allow procedural deck rules to recruit these characters and automatically assign them a valid starting site (via {Leader.Tag:Resolved Site}), we can batch-tag all 15 characters in under 30 seconds:

  1. Scope the Master List: In the main window, check The Lidless Eye (MELE) in the Set menu, and set Filter Slot 1: Attribute: Home, Value: Any Dark-hold.
  2. Configure the Extraction Tool: Open Tools > Extract Taxonomy with Rules..., choose Custom Regex Expression, and enter:
    • Pattern: Any Dark-hold
    • Tag Name: Barad-dûr; Carn Dûm; Cirith Gorgor; Cirith Ungol; Dol Guldur; Minas Morgul; Urlurtsu Nurn
    • Save to Category: Resolved Site
  3. Preview and Apply: Click Test / Preview Matches to verify the 15 characters, then click Apply Tags to Catalog. Persist your changes via Filter > Save Tag Set... overwriting Rules_Support_Tags.json.

Load Rules from File (.json)

For large-scale taxonomy extraction across multiple expansions, you can author batch extraction rule files (.json) containing arrays of compiled regex rules and execute them in a single operation.

Sample Batch Extraction Schema

[
  {
    "Category": "Faction Bonus",
    "Pattern": "(?i)\\+2\\s+direct\\s+influence\\s+against\\s+([A-Za-z\\s-]+)",
    "TagTemplate": "$1"
  },
  {
    "Category": "Resolved Site",
    "Pattern": "Any Dark-hold",
    "TagTemplate": "Barad-dûr; Carn Dûm; Cirith Gorgor; Dol Guldur; Minas Morgul"
  }
]
