Taxonomy Extraction Tools

Located under Tools > Extract Taxonomy with Rules..., this dialog provides automated classification tools scoped strictly to the cards currently visible in your Master List. It allows you to harvest card text, perform cross-card relational joins, or run custom regular expressions to tag hundreds of cards in bulk.

1. Dynamic Entity Harvesting (from Catalog Text)

  • Entity Harvest: Select any canonical card rules attribute and value (e.g. Secondary = Faction or Primary = Region). The app scans active sets in memory, harvests all matching entity titles (e.g. Wood-elves, Riders of Rohan), and searches your scoped Master List cards for gameplay references to those titles.
  • Flavor Text Protection: All Tolkien book quotes (enclosed in quotation marks) and book citations (e.g. —LotRI) are automatically stripped before evaluation, preventing lore quotes from generating false-positive tags.

2. Relational Attribute Lookup (Cross-Card Join)

Enables 2-step relational tagging between linked entities:

  • Source Field: Reads an attribute from cards in scope (e.g. Character Home).
  • Lookup Entity: Matches corresponding cards in the catalog (e.g. Primary = Site).
  • Extract Field: Reads the destination attribute (e.g. Site Region) and writes it into a custom category (e.g. Home Region).
  • Compound Token Parsing: Characters with multiple homesites (e.g. Rivendell, Bree) automatically resolve both sites to generate semicolon-delimited multi-tags (Arthedain; Rhudaur).

3. Custom Regex Expressions (Mode 3)

Mode 3 allows you to test and execute arbitrary .NET regular expressions against the rules text of cards currently in scope. It provides three configurable fields:

Field Description & Behavior Examples
Category The destination custom taxonomy category where extracted tags will be stored. Resolved Site, Combat Role, Audit
Tag Name The value assigned to matching cards. Supports two modes:
  • Static Tag / List: Enter a fixed string or semicolon-separated list. Every matching card receives this exact value.
  • Regex Capture Group ($1): If your pattern contains parentheses (...), using $1 dynamically assigns the exact word or phrase matched inside that group.
 Barad-dûr; Carn Dûm; Cirith Gorgor
Scout Specialist
$1
Pattern The regular expression evaluated against card rules text. Useful flags:
  • (?i): Case-insensitive matching.
  • (?s): Dot-all (singleline) mode, allowing .* to span across multi-line card text paragraphs.
  • \b: Word boundary (ensures \bdragon\b matches "dragon" but not "dragonfly").
 (?i)Any Dark-hold
(?i)\b(greater)\b
(?is)(?=.*dragon)(?=.*ruin).*
Automatic Flavor Text Stripping: The regex engine automatically strips Tolkien book quotes ("...") and book attributions (e.g. —LotR, -Hobbit) before evaluating your pattern. Trailing card text like Home Site: is preserved, ensuring your regex searches only active gameplay mechanics.

4. Worked Walkthrough: Batch-Tagging Minion Dark-holds

In The Lidless Eye, 15 Minion Orcs, Trolls, and Half-orcs (such as Doeth, Orc Captain, and Troll Lout) have the non-specific home rule Home Site: Any Dark-hold. To allow procedural deck rules to recruit these characters and automatically assign them a valid starting site (via {Leader.Tag:Resolved Site}), we can batch-tag all 15 characters in under 30 seconds:

Step 1: Scope the Master List to the Target Characters

  1. In the main window, check The Lidless Eye (MELE) in the Set menu.
  2. Set Filter Slot 1: Attribute: Home, Value: Any Dark-hold.
  3. The Master List immediately displays all 15 matching minion characters.

Step 2: Configure Mode 3 in the Extraction Tool

  1. Open Tools > Extract Taxonomy with Rules.... Notice the hint confirming: "Scanning 15 card(s) currently visible in the Master List."
  2. Select the Custom Regex Expression radio button.
  3. Fill in the extraction parameters:
    • Category: Resolved Site
    • Tag Name: Barad-dûr; Carn Dûm; Cirith Gorgor; Cirith Ungol; Dol Guldur; Minas Morgul; Urlurtsu Nurn
    • Pattern: (?i)Any Dark-hold

Step 3: Preview and Apply

  1. Click Test / Preview Matches. The preview table populates with all 15 characters, showing each will receive the 7 surface Dark-holds in their tag.
  2. Click Apply Tags to Catalog. All 15 cards are tagged simultaneously in memory.
  3. Select Filter > Save Tag Set... (or Filter > Merge Tag Set...) to persist your new mappings to Rules_Support_Tags.json.

5. Batch JSON Rule Sets (Mode 4)

For large-scale taxonomy extraction across multiple expansions, you can author reusable batch extraction rule files (.json) containing arrays of compiled regex rules and load them via the Load Rules from File option.

Sample Extraction Rule Schema

[
  {
    "Category": "Faction Bonus",
    "Pattern": "(?i)\\+2\\s+direct\\s+influence\\s+against\\s+([A-Za-z\\s-]+)",
    "TagTemplate": "$1"
  },
  {
    "Category": "Resolved Site",
    "Pattern": "(?i)Any Dark-hold",
    "TagTemplate": "Barad-dûr; Carn Dûm; Cirith Gorgor; Dol Guldur; Minas Morgul"
  }
]
