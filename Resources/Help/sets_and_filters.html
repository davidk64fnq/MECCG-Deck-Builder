Sets & Filter Management

Managing Sets

Click the Set menu in the top bar to toggle expansions. You can combine multiple sets at will:

  • Select All: Enables every available official and Dreamcard expansion.
  • Clear All: Deselects all expansions.
  • Individual Sets: Check or uncheck individual sets (e.g. The Wizards, Dark Minions, The Lidless Eye, The Balrog, or Dreamcard expansions).

Cardnum Built-in Filters (Slots 1 & 2)

The first two key-value pairs at the bottom-left filter cards based on official metadata:

Attribute Key Typical Filter Values
Primary Character, Resource, Hazard, Site, Region
Secondary Ally, Faction, Creature, Short-event, Long-event, Permanent-event, Minor Item, Major Item, Greater Item, etc.
Alignment Hero, Minion, Fallen-wizard, Balrog, Neutral
Race Dúnadan, Dwarf, Elf, Hobbit, Man, Wizard, Orc, Troll, Dragon
Skill Warrior, Scout, Ranger, Sage, Diplomat
Site / Region Free-hold, Border-hold, Ruins & Lairs, Shadow-hold, Dark-hold, Haven
Prowess / Body / Mind / MPs Numeric stats and victory point values
Multi-Skill Search: When searching by Skill, cards with compound skills (such as Warrior/Scout) are indexed by both terms individually.

Custom User Filters (Slots 3 & 4)

You can create your own custom tagging system to classify cards (e.g., categorizing cards by strategy: Archetype → Ring Destruction or Faction Rush):

1. Creating a New Custom Key

  1. Click into the text box of ComboBoxKey3 or ComboBoxKey4.
  2. Type the new key name (e.g., Strategy) and press Tab or click away to commit.

2. Adding Values to a Key

  1. Select the newly created key in Key Slot 3 or 4.
  2. Type a new value into Value3 or Value4 (e.g., One Ring Victory) and leave the box to commit.

3. Assigning Custom Tags to Cards

  1. Right-click any card in the Master List.
  2. Navigate to Add Key Value > [Your Key Name] > [Your Value].

4. Saving and Opening Custom Filter Sets

  • Choose Filter > Save to save your custom tag taxonomy and card assignments to a .json file.
  • Choose Filter > Open to load a previously saved filter file.
  • Use Filter > Delete Key to remove obsolete custom keys or individual values.
