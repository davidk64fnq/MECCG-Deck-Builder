Sets & Filter Management

Managing Card Sets

Click the Set menu in the top bar to choose which expansions are active in the Master List. You can combine multiple sets at will:

  • Select All: Enables all official sets and Dreamcard expansions.
  • Clear All: Deselects all expansions.
  • Individual Sets: Check or uncheck individual expansions (e.g., The Wizards, The Dragons, Dark Minions, The Lidless Eye, The Balrog, or player council Dreamcard sets).

Dual-Layer Filtering Architecture

Located beneath the main workspace, four pairs of ComboBoxes provide fine-grained search and deck analysis. The filter bar is organized into two distinct layers:

Filter Layer Data Source User Modifiability Input Style
Slots 1 & 2:
Built-in Database Filters 		Cardnum Open Database: Canonical card statistics synchronized from cardnum.net and GitHub, representing published cards from Iron Crown Enterprises (I.C.E.) and Council of Elrond Dreamcards. Read-Only: Attributes and values are fixed. You cannot type into, edit, or delete items in these two slots. Fixed Drop-Down Selection list.
Slots 3 & 4:
Custom User Taxonomy 		User-Defined: Managed locally in your deck builder session and saved to custom filter files (.json). Completely Alterable: You can invent new keys, type new values, assign them to cards via right-click, or delete them globally. Editable Text ComboBox (type new entries directly or pick from existing values).

Cardnum Built-in Filters (Slots 1 & 2)

The two left-hand key-value selectors filter the catalog using official card attributes. Because these properties reflect canonical game rules, they are strictly read-only:

Custom User Filters (Slots 3 & 4)

The two right-hand slots allow you to create your own classification system to tag cards by playstyle, hazard package, or deck archetype (e.g., Archetype → Ring Destruction or Role → Scout Support).

1. Creating a New Custom Key

  1. Click directly into the text box of ComboBoxKey3 or ComboBoxKey4.
  2. Type your new key name (e.g., Strategy) and press Tab or click away to commit.

2. Adding Values to a Key

  1. Select or type the desired key in Key Slot 3 or 4.
  2. Click into the corresponding Value3 or Value4 box.
  3. Type a new value (e.g., One Ring Victory) and press Tab or click away to commit.

3. Assigning Custom Tags to Cards

  1. Right-click any card in the Master List.
  2. Navigate to Add Key Value > [Your Key Name] > [Your Value].
  3. The card is immediately associated with that tag. You can view all custom tags on a card by right-clicking it and inspecting the Custom Filters section.

4. Deleting Custom Keys and Values

The application supports selective deletion at three distinct levels:

Operation How to Perform Scope & Impact
Delete Entire Key
(Key & all associated values)		 Open Filter > Delete Key and click directly on the Key Name (the parent menu item itself; do not expand the fly-out sub-menu). Permanently deletes the key category, removes all of its associated values, strips that tag from every card in the database, and clears any active filter slots currently using that key.
Delete Single Key Value
(Individual leaf value)		 Open Filter > Delete Key, hover over the Key Name to expand its fly-out sub-menu, and click the specific Value. Deletes only that individual value from the key taxonomy and removes it from all cards tagged with it. The parent key and all other sibling values remain intact.
Unassign Tag from Single Card Right-click the card in the Master List or Deck Tab, then select Delete Key Value > [Key] > [Value]. Only removes the tag from that specific card. The key and value remain preserved in your taxonomy for use on other cards.
Global Database Scope: Deleting a key or value via Filter > Delete Key permanently removes it across the entire card database. This affects all cards and all expansions, including sets that are currently unchecked or hidden in the Set menu.

If you only wish to remove a tag from specific cards without deleting the term from your taxonomy, right-click the card directly and use Delete Key Value > [Key] > [Value] instead.
Real-time Synchronization: Whenever a key or value is created or deleted, both custom filter slots (Slots 3 and 4) refresh their drop-down lists immediately in real time, even if both slots are currently configured to the same key. If a deleted item was actively selected, the slot automatically resets to blank.

5. Saving and Opening Custom Filter Sets

  • Filter > Save: Exports your entire custom taxonomy and all card tag assignments to a portable .json file.
  • Filter > Open: Loads a previously saved custom filter set, restoring all keys, values, and card mappings.
