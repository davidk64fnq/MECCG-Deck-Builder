Sets & Filter Management

Managing Card Sets

Click the Set menu in the top bar to choose which expansions are active in the Master List. You can combine multiple sets at will:

  • Select All: Enables all official sets and Dreamcard expansions.
  • Clear All: Deselects all expansions.
  • Individual Sets: Check or uncheck individual expansions (e.g., The Wizards, The Dragons, Dark Minions, The Lidless Eye, The Balrog, or player council Dreamcard sets).

Dual-Layer Filtering Architecture

Cascading Faceted Search & Conflict Resolution

The filter system operates as an order-independent faceted search engine. All four slots continuously communicate with each other and with the active expansion set selections:

  • Context-Sensitive Value Pruning: The value dropdown for any slot only displays options present among cards that satisfy your active expansion sets and the other active filter slots. Selecting any choice from a dropdown is guaranteed to match at least one card, completely eliminating dead-end queries.
  • Order-Independent (Symmetric) Narrowing: You can choose filters in any order. For example, selecting Skill = Diplomat in Slot 2 first will automatically prune Slot 1's Secondary dropdown down to only card types that feature diplomats (Ally, Avatar, Character and Short-event).
  • Automatic Conflict Resolution: If an existing filter selection becomes impossible—such as deselecting an expansion in the Set menu or deleting a custom tag in the taxonomy manager—the invalid slot automatically and silently resets to blank ("").
  • Cross-Layer Integration: Custom tags in Slots 3 & 4 participate fully in faceting. Selecting a custom archetype (e.g., Archetype → Ring Destruction) will prune the Cardnum dropdowns (Slots 1 & 2) to only show primary types, races, and skills present on cards tagged with that archetype.
  • Expansion Set Pruning: Checking or unchecking sets in the Set menu dynamically recalculates available filter values. If all expansions are deselected, the master list and card image preview are cleared.

Custom User Taxonomy (Slots 3 & 4)

The two right-hand slots allow you to filter cards by your own classification system (e.g., Archetype → Ring Destruction or Role → Scout Support). Authoring and managing tags is cleanly decoupled from filtering:

1. Managing the Taxonomy (Filter > Manage Custom Tags...)

Open Filter > Manage Custom Tags... to access the central tag management dialog. Here you can:

  • Add Categories: Create new classification categories (e.g., Archetype, Hazard Package, Role).
  • Rename Categories or Tags: Rename terms across your entire taxonomy; all tagged cards are updated automatically.
  • Add Tags: Add new tags under an existing category.
  • Delete Categories or Tags: Safely remove terms from the database and strip them from tagged cards.

2. Assigning Custom Tags to Cards

You can tag cards in the Master List or any Deck Tab using the context menu:

  • Assign or Reassign Existing Tag: Right-click a card and select Assign Tag > [Category] > [Tag]. The category menu displays a checkmark (✓) next to the currently assigned tag; selecting a different tag seamlessly updates and remaps the card.
  • Author and Assign New Tag: Right-click a card and select Assign Tag > [+ Author New Tag...]. This prompts for both category and tag, registers them into your taxonomy, and assigns them to the card in a single action without affecting your active filter bar.
  • Add New Tag to Existing Category: Right-click a card and select Assign Tag > [Category] > [+ Add Tag...] to author a new tag and assign it immediately.

3. Removing Tags from Cards

  • Remove Tag from Single Card: Right-click the card and choose Remove Tag > [Category] > [Tag]. The tag is unassigned from that card, but remains in your taxonomy for other cards.
  • Delete Globally: Use Filter > Manage Custom Tags... to permanently delete a category or tag across all cards in the catalog.

4. Saving and Loading Custom Tag Sets

  • Filter > Save Tag Set...: Exports your entire custom taxonomy and all card tag assignments to a portable .json file.
  • Filter > Load Tag Set...: Loads a previously saved custom tag set, restoring all categories, tags, and card mappings.

Automated Taxonomy & Spreadsheet Tools

In addition to authoring tags manually, the application provides an automated extraction engine and a round-trip CSV spreadsheet pipeline under the Tools menu:

1. Dynamic Entity Harvesting & Regex Rules (Tools > Extract Taxonomy with Rules...)

Opens an extraction dialog scoped to cards currently visible in the Master List:

  • Dynamic Entity Harvest: Select any canonical card rules attribute and value (e.g. Secondary = Faction or Primary = Region). The app automatically scans the active sets in memory, extracts all matching entity titles, and searches your Master List cards for references to those entities.
  • Flavor Text Protection: All Tolkien book quotes and citations (enclosed in quotation marks) are automatically stripped before rules evaluation, preventing lore text from creating false-positive tags.
  • Custom Regex & JSON Rule Files: Test individual regular expressions in real-time or load batch rule sets from portable .json files.
  • Preview & Apply: Review matches in the preview grid before choosing to either export a CSV draft or apply tags directly into your active taxonomy.

2. Spreadsheet Collaboration (CSV Draft Export & Import)

Enables collaborative review and mass editing in Google Sheets or Microsoft Excel:

  • Export Taxonomy Draft (CSV): Exports a spreadsheet containing only cards matching your current set and filter slot criteria. Includes Card Name, Set, Primary, a template category column, and full Card Text for reference.
  • Multi-Tag Syntax: To assign multiple tags within the same category to a single card, separate them with a semicolon (;), for example: Elf Factions; Iron Hill Dwarves.
  • Import Taxonomy from CSV: Ingests reviewed spreadsheets directly into the Deck Builder. Columns are mapped automatically to categories, placeholder text is safely ignored, and tags are mapped to stable card identifiers (FullCode, Name, Set).

3. Multi-Tag Assignment via Context Menus

Cards can hold multiple tags within the same custom category:

  • Toggle On / Off: In the Assign Tag menu, currently assigned tags display a checkmark (✓). Clicking an unchecked tag adds it; clicking a checked tag unchecks and removes it.
  • Granular Removal: The Remove Tag menu displays each assigned tag individually, allowing you to remove a specific tag without clearing the entire category.

Clearing and Resetting Filters

Method Shortcut / Gesture Scope & Behavior
Global Reset Menu: Filter > Clear All Filters
Keyboard: Ctrl+R 		Instantly resets all four filter slots (Slots 1–4) to blank and refreshes the master card list.
Slot Context Menu Right-Click any of the 8 filter ComboBoxes Opens a context menu with options to:
  • Clear This Filter: Resets both the category/attribute and value of that specific slot to blank.
  • Clear All Filters: Resets all four slots at once.
Quick Keyboard Reset Escape When focused inside any category or tag ComboBox, pressing Escape immediately resets that box to the blank ("") entry.
Manual Dropdown Reset Select the top blank entry ("") Selecting the empty item at the top of any category dropdown resets that slot and clears its paired tag list.

Importing Custom Taxonomies via Spreadsheet (CSV)

To facilitate large-scale taxonomy creation, community sharing, and collaborative review in Google Sheets or Microsoft Excel, MECCG Deck Builder supports round-trip CSV draft exporting and importing via the Tools menu.

Spreadsheet Column Layout

Column Header Required? Description & Behavior
Card Name Required Exact card title (e.g. Anborn, Adrazar). Matches cards in the catalog.
Set Required Expansion code (e.g. METW, MEDM, MELE) used to disambiguate reprint cards.
Primary Optional Official primary type (e.g. Character). Read-only; ignored during import.
[Custom Category Columns] Optional Any header (e.g. Faction Focus, Role, Hazard Archetype) becomes a custom category. Cell contents are imported as tags.
Card Text Optional Full rules text provided for reference during spreadsheet verification. Ignored during import.
Multi-Tagging Syntax: To assign multiple tags within the same category to a card, separate them with a semicolon (;), for example: Dwarf Factions; All Factions or Scout Support; Ranger Buffer.

Step-by-Step Workflow

  1. Generate a Draft: Click Tools > Export Taxonomy Draft (CSV)... (or use Tools > Extract Taxonomy with Rules...) to extract faction bonuses or rule matches into a .csv file.
  2. Review in Google Sheets / Excel: Open the CSV, inspect extracted tags side-by-side with Card Text, adjust or author new category columns, and download as Comma Separated Values (.csv).
  3. Ingest into Deck Builder: Select Tools > Import Taxonomy from CSV.... Categories and tags immediately populate filter dropdowns and card context menus.
