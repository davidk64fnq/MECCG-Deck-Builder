MECCG Deck Builder

MECCG Deck Builder is a dedicated Windows desktop application designed to build, organize, filter, and export decks for the Middle-earth Collectible Card Game (MECCG) published by Iron Crown Enterprises (I.C.E.), including official expansions and player council Dreamcard sets.

Key Capabilities

  • Live Data Integration: Synchronizes cards and expansion sets from the Cardnum open database, with seamless local offline JSON fallbacks.
  • On-Demand Image Preview & Caching: Displays high-resolution card artwork downloaded on demand and cached locally to conserve bandwidth.
  • Five-Section Deck Partitioning: Organizes cards into standard MECCG deck sections: Pool, Resources, Hazards, Sideboard, and Sites.
  • Dual Filtering Engine: Filter the card catalog simultaneously by official Cardnum metadata (rarity, race, skills, items, alignments) and customizable user-defined tags.
  • Multi-Platform Exporting: Directly export decks to Tabletop Simulator (TTS), Play MECCG online client (including PBEM format), Cardnum list format, structured text archives, or plain text lists.

Quick Start Guide

  1. Select Card Sets: Click Set in the top menu bar to check the expansions you want to browse (defaults to The Wizards).
  2. Filter Cards: Use the dropdown menus at the bottom left to filter by card properties (such as Primary = Character, Race = Dúnadan).
  3. Add Cards to Your Deck:
    • Double-click any card in the Master List to add it to the active tab on the right.
    • Or drag and drop cards directly into any deck tab.
    • Or right-click a card in the Master List and choose Copy > [Target Tab].
  4. Review Title Bar Counters: Watch the window title update dynamically with card counts: MECCG Deck Builder - "DeckName" (Pool/Resources[Characters]/Hazards/Sideboard/Sites).
  5. Save or Export: Choose File > Save to keep your deck in native JSON format, or File > Export to generate files for Tabletop Simulator or Play MECCG.
