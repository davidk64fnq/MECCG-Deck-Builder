Deck Building Operations

Managing Decks via the Deck Menu

  • New Deck (Ctrl+N): Clears all five deck partitions to start fresh.
  • Open Deck... (Ctrl+O): Opens an assembled deck instance from a native JSON save file.
  • Save Deck (Ctrl+S): Saves the current deck instance to disk.
  • Save Deck As...: Saves the deck under a new file title.
  • Export Deck... (Ctrl+E): Exports the deck to Tabletop Simulator, Play MECCG, Cardnum, Archive, or Text format.

Adding Cards

  • Fastest Method: Switch to your desired deck tab on the right, find the card in the Master List, and double-click it. (Note: Double-clicking continues to deposit cards into your active deck partition even when the Card Taxonomy inspector view is currently visible).
  • Drag and Drop: Left-click and drag the card from the Master List onto any visible tab list.
  • Targeted Right-Click: Right-click a card in the Master List, open the Copy submenu, and pick the destination tab (Pool, Resources, Hazards, Sideboard, Sites). This automatically switches focus to that tab.

Duplicating Cards

To add another copy of a card already in a deck tab, simply double-click it directly within that tab's list.

Moving Cards Between Tabs

  1. Right-click the card inside any deck tab.
  2. Highlight Move.
  3. Select the destination tab. The card is added to the target tab and removed from the current tab.

Deleting Cards

  • Right-click the card in the deck tab and select Delete.
