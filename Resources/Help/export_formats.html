Multi-Platform Export Formats

Select Deck > Export Deck... (Ctrl+E) to open the export dialog and choose from the supported formats:

Format Extension Target Platform & Usage
Tabletop Simulator .json Generates five JSON deck files (one for each section: _pool.json, _resource.json, _hazard.json, _sideboard.json, _site.json) formatted for Tabletop Simulator's Saved Objects folder with cloud image links.
Play MECCG .play Standard export for the online Play MECCG client. Formats cards with parenthetical subtitle conventions (e.g. Adrazar (TW)) using Windows-1252 ANSI encoding.
Cardnum Deck .cnum Exports deck listings using standard Cardnum code prefixes (e.g. 1 Adrazar (TW)) grouped by deck sections.
Archive Listing .archive A structured analysis format that breaks down your deck by category: Items (Minor, Major, Greater, Ring), Events (Short, Long, Permanent), Allies, Factions, Characters by race, and Sites by type.
Text File .txt A clean, human-readable plain text breakdown of all deck sections with section headers.
