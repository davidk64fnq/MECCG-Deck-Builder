1. Fine-Tuning Item Drafts (Weapons, Armor & Lost Knowledge)

In Cardnum, the Race attribute on Resource cards is overloaded to categorize item sub-types. You can use this to draft specific gear categories rather than drawing random items:

A. Martial Combat Gear (Weapons & Armor Only)

Draft combat-ready gear while excluding tomes, rings, and cloaks: 

{
  "Name": "Warrior Equipment",
  "Section": "Resources",
  "Count": 3,
  "Attributes": {
    "Primary": "Resource",
    "Secondary": "Major Item; Minor Item",
    "Race": "Weapon; Armor"
  }
}

B. Lore & Quest Tomes (Lost Knowledge)

Certain quest strategies (such as destroying items in Mount Doom or scoring lore victory points) require ancient writings. Query the Lost Knowledge keyword directly: 

{
  "Name": "Ancient Lore Tomes",
  "Section": "Resources",
  "Count": 2,
  "Attributes": {
    "Primary": "Resource",
    "Race": "Lost Knowledge"
  }
}

2. The Zero-Corruption Gear Package

Heavy items often inflict corruption points (CP) that burden characters with corruption checks. Use the blank sentinel ("[Blank]") to draft risk-free weapons, shields, and cloaks: 

{
  "Name": "Safe Utility Items",
  "Section": "Resources",
  "Count": 4,
  "Attributes": {
    "Primary": "Resource",
    "Secondary": "Minor Item; Major Item",
    "Corruption": "[Blank]"
  }
}

3. Automated Ring Expeditions (Items & Sites)

Gold Ring items do not have fixed play sites; they are playable at any site that prints a gold ring in its playable box. Pair rings with suitable destination sites dynamically: 

[
  {
    "Name": "Testing Rings",
    "Section": "Resources",
    "Count": 2,
    "Attributes": {
      "Primary": "Resource",
      "Secondary": "Gold Ring Item"
    }
  },
  {
    "Name": "Ring Testing Sites",
    "Section": "Sites",
    "Count": 3,
    "Attributes": {
      "Primary": "Site",
      "GoldRing": "yes"
    }
  }
]

4. Dragon Lair Expeditions & Hoard Relics

Hoard items (such as Glamdring, Orcrist, or The Arkenstone) can only be played at sites that contain a dragon hoard. Guarantee that your deck draws legal destination sites: 

[

    "Name": "Dragon Hoard Items",
    "Section": "Resources",
    "Count": 2,
    "Attributes": {
      "Primary": "Resource",
      "Hoard": "yes"
    }
  },
  {
    "Name": "Hoard Lair Destinations",

    "Count": 2,
    "Attributes": {
      "Primary": "Site",
      "Hoard": "yes",
      "Automatic Attack": "Dragon"
    }
  }
]

5. Aligning Diplomats with Corresponding Factions

When capturing a diplomat leader via "SaveAs": "Leader", query their associated faction bonus using dynamic predicates. Using Race=Elf or Race=Man ensures species-wide diplomatic bonuses recruit matching factions: 

{
  "Name": "Leader's Associated Faction",
  "Section": "Resources",
  "Count": 1,
  "Attributes": {
    "Primary": "Resource",
    "Secondary": "Faction",
    "Name": "{Leader.Category:Faction Bonus}"
  },
  "Fallback": {
    "Name": "Generic Faction by Race",
    "Attributes": {
      "Primary": "Resource",
      "Secondary": "Faction",
      "Race": "{Leader.Race}"
    }
  }
}

7. Handling Dual-Mode & Modal "OR" Cards

Certain cards offer split functionality—either via dual card types (such as Nazgûl with Creature/Permanent-event) or through modal "OR" rules text (such as Dragon's Desolation).

The Guiding Principle — Restrictions vs. Permissions:
Why do we tag the restriction on a Nazgûl, but leave Dragon's Desolation blank?
  • Restrictions (Tag them): A Nazgûl's creature mode is legally barred outside its printed regions. We tag those regions so the generator never drafts it as an illegal creature in Eriador.
  • Permissions (Leave blank): Dragon's Desolation is always legal anywhere on Middle-earth under its primary mode. Its Ruins & Lairs clause is an optional alternative permission, not a play barrier. Leaving it [Blank] ensures the generator recognizes it as a universally playable card.

A. Drafting Dual Cards as Creatures (Strictly Regional)

Several hazards (like the Nazgûl) possess dual secondary types. Often, their Creature mode is restricted to specific geographic regions (e.g., Gorgoroth, Khand), while their Event mode is playable anywhere.

Tagging Best Practice: Only tag the strict creature regions in your custom taxonomy (e.g., Region Requirement: Gorgoroth; Khand). Do not add "All" or "Anywhere" for the event side, as that would cause the generator to falsely draft them as creatures in illegal regions like the Shire. 

{
  "Name": "Gorgoroth Guardians",
  "Section": "Hazards",
  "Count": 2,
  "Attributes": {
    "Secondary": "Creature"
  },
  "Categories": {
    "Region Requirement": "Gorgoroth"
  }
}

B. Drafting Dual Cards as Events (Globally Available)

{
  "Name": "Exhaustion Hazard Events",
  "Section": "Hazards",
  "Count": 2,
  "Attributes": {
    "Primary": "Hazard"
  },
  "Categories": {
    "Role": "Exhaustion"
  }
}

C. Modal "OR" Events (Global Effect vs. Keying Enabler)

Cards like Dragon's Desolation offer a universally playable mode (buffing any Dragon attack anywhere) OR an alternative enabling clause (keying a Dragon hazard creature to Ruins & Lairs with wilderness).

  • Tagging Best Practice: Leave Site Requirement and Region Requirement [Blank].
  • Why: The card does not mandate a Ruins & Lairs site to be legally played. Tagging the site condition would prevent open hazard rules (such as "Site Requirement": "[Blank]") from drafting the card to support wandering Dragon creatures or lair automatic-attacks.
{
  "Name": "Open Dragon Enhancements",
  "Section": "Hazards",
  "Count": 2,
  "Attributes": {
    "Primary": "Hazard"
  },
  "Categories": {
    "Role": "Combat",
    "Target Species": "Dragon",
    "Site Requirement": "[Blank]"
  }
}

8. Leader Signature Cards & Skill Shielding

Certain resource cards can only be played if a specific unique character is in your company (such as Return of the King for Aragorn II), or if your company includes a specific character class (such as Ranger only on Anduin River, Sage only on Align Palantír, or Scout only on Concealment).

A. Dynamic Signature Event Recruitment

Draft signature events tailored dynamically to whatever leader is randomly chosen—without hardcoding card titles: 

{
  "Name": "Leader's Unique Signature Card",
  "Section": "Resources",
  "Count": 1,
  "Attributes": {
    "Primary": "Resource",
    "Specific": "{Leader.Name}"
  },
  "Fallback": {
    "Name": "Generic Utility Influence",
    "Attributes": {
      "Primary": "Resource",
      "Specific": "[Blank]"
    },
    "Categories": {
      "Role": "Influence"
    }
  }
}

If the captured leader is Aragorn II, {Leader.Name} resolves to "Aragorn II", matching and drafting Return of the King. If the leader has no signature cards (such as Balin), the query finds 0 matches and cleanly executes the fallback.

B. Excluding Signature Cards from Generic Draws

To prevent a generic resource query from accidentally drafting Return of the King into a deck led by Gimli, query "Specific": "[Blank]": 

{
  "Name": "Open Utility Resources",
  "Section": "Resources",
  "Count": 3,
  "Attributes": {
    "Primary": "Resource",
    "Specific": "[Blank]"
  },
  "Categories": {
    "Role": "Influence"
  }
}

C. Shielding Generic Draws from Class & Skill Locks

In Cardnum, class restrictions on resource and hazard events are indexed directly under the official Skill attribute (e.g. Skill: Ranger on Anduin River, or Skill: Sage on Reforging).

When drafting open utility cards for an arbitrary company, combine "Skill": "[Blank]" with "Specific": "[Blank]" to ensure that every drafted card can be played by any company, with zero risk of dead cards: 

{
  "Name": "Universal Movement & Protection Events",
  "Section": "Resources",
  "Count": 3,
  "Attributes": {
    "Primary": "Resource",
    "Skill": "[Blank]",
    "Specific": "[Blank]"
  },
  "Categories": {
    "Role": "Movement; Protection"
  }
}

9. Connected Under-deeps Expeditions (Guaranteed Surface Entrances)

Under-deeps sites (introduced in The Dragons and expanded in The Lidless Eye and The Balrog) exist in a subterranean layer beneath Middle-earth. Companies cannot reach them via standard region movement; they must start at an adjacent surface site and make an Under-deeps movement test.

The "No Orphans" Rule: An Under-deeps site drafted without its corresponding surface entrance is completely unplayable in game—your company can never travel there. The patterns below use the companion category Adjacent Sites to guarantee that every Under-deeps lair drafted brings its legal surface entrance into the site deck automatically.

A. Destination-First: Draft a Deep Lair, Auto-Draft its Surface Entrance

Draft any Under-deeps destination site, then automatically draft its legal surface entrance by filtering for "Adjacent Sites": "[Blank]": 

[
  {
    "Name": "Subterranean Expedition Target",
    "SaveAs": "DeepLair",
    "Section": "Sites",
    "Count": 1,
    "Categories": {
      "Adjacent Sites": "!=[Blank]"
    }
  },
  {
    "Name": "Required Surface Entrance",
    "Section": "Sites",
    "Count": 1,
    "Attributes": {
      "Primary": "Site",
      "Name": "{DeepLair.Category:Adjacent Sites}"
    },
    "Categories": {
      "Adjacent Sites": "[Blank]"
    }
  }
]

How it works:

  • Rule 1 selects an Under-deeps site (such as The Drowning-deeps) and captures it as DeepLair.
  • Rule 2 expands {DeepLair.Category:Adjacent Sites} into "Blue Mountain Dwarf-hold; Remains of Thangorodrim; The Under-vaults".
  • Because Rule 2 also requires "Adjacent Sites": "[Blank]", the deeper subterranean sites (which carry tags) are excluded, leaving only the surface entrance (Blue Mountain Dwarf-hold) to be drafted!

B. Base-First: Draft a Surface Hold, Auto-Draft a Connected Deep Lair

Alternatively, start from a chosen surface haven or hold and recruit a deep site that lists that hold in its adjacencies: 

[
  {
    "Name": "Surface Stronghold",
    "SaveAs": "SurfaceHold",
    "Section": "Sites",
    "Count": 1,
    "Attributes": {
      "Primary": "Site",
      "Name": "Blue Mountain Dwarf-hold"
    }
  },
  {
    "Name": "Accessible Under-deeps Site",
    "Section": "Sites",
    "Count": 1,
    "Categories": {
      "Adjacent Sites": "{SurfaceHold.Name}"
    }
  }
]

Rule 2 queries all Under-deeps sites whose semicolon-separated Adjacent Sites tag contains Blue Mountain Dwarf-hold, successfully matching and adding The Drowning-deeps without hardcoded site pairings.

10. The Universal Quest & Storyline Engine

Certain scenario objectives require a full package of connected cards—a champion hero, a destination site, a starting site, and a prerequisite enabler card. (For example, Army of the Dead requires Aragorn II, movement from Dunharrow to Vale of Erech, and the event Paths of the Dead).

By chaining SaveAs variables with fallback routing, a single generic 5-rule block can draft any random quest from your catalog and automatically pull in every required card without hardcoding titles: 

[
  {
    "Name": "Random Scenario Quest",
    "SaveAs": "Quest",
    "Section": "Resources",
    "Count": 1,
    "Categories": {
      "Role": "Quest"
    }
  },
  {
    "Name": "Quest Champion Hero",
    "Section": "Pool",
    "Count": 1,
    "Attributes": {
      "Primary": "Character",
      "Name": "{Quest.Specific}"
    },
    "Fallback": {
      "Name": "Generic Companion",
      "Attributes": {
        "Primary": "Character"
      }
    }
  },
  {
    "Name": "Quest Enabler Card",
    "SaveAs": "Enabler",
    "Section": "Resources",
    "Count": 1,
    "Attributes": {
      "Primary": "Resource",
      "Name": "{Quest.Category:Prerequisite}"
    },
    "Fallback": {
      "Name": "Open Resource Support",
      "Categories": {
        "Role": "Card Flow; Protection",
        "Prerequisite For": "[Blank]"
      }
    }
  },
  {
    "Name": "Quest Destination Site",
    "Section": "Sites",
    "Count": 1,
    "Attributes": {
      "Primary": "Site",
      "Name": "{Quest.Category:Site Requirement}"
    }
  },
  {
    "Name": "Quest Origin / Enabler Site",
    "Section": "Sites",
    "Count": 1,
    "Attributes": {
      "Primary": "Site",
      "Name": "{Enabler.Category:Site Requirement}"
    },
    "Fallback": {
      "Name": "Open Adventure Site",
      "Attributes": {
        "Primary": "Site"
      }
    }
  }
]
Shielding Generic Resource Draws:
To ensure that quest enablers (like Paths of the Dead) are never drawn by generic utility rules into non-quest decks, add "Prerequisite For": "[Blank]" to all open resource rules: 
"Categories": {
  "Role": "Card Flow; Protection",
  "Prerequisite For": "[Blank]"
}

11. Geographic Theaters & Contiguous Movement Paths

Procedural deck generation templates can establish cohesive Middle-earth operational theaters using Middle-earth's Adjacent Regions adjacency graph:

A. Haven-Tethered Starter Hub (0 Region Cards)

Anchor your expedition to Rivendell (or a randomly chosen haven) using pure Starter Movement without diluting your site deck with region cards: 

[
  {
    "RuleType": "GeographicTheater",
    "Name": "Rivendell Expedition Hub",
    "Mode": "Starter Only",
    "Haven": "Rivendell",
    "RegionCount": 4
  },
  {
    "Name": "Regional Adventure Sites",
    "Section": "Sites",
    "Count": 6,
    "Attributes": {
      "Primary": "Site",
      "Region": "{Theater.Region}"
    }
  }
]

B. Contiguous Roaming Cluster with Overland Pathfinding

Roam freely through a cluster of up to 4 contiguous regions around Lórien, automatically drafting the region cards, starting haven (*Rivendell*), and the shortest overland BFS hiking route: 

[
  {
    "RuleType": "GeographicTheater",
    "Name": "Southern Mirkwood Theater",
    "Mode": "Starter + Region",
    "Haven": "Lórien",
    "RegionCount": 4,
    "IncludeOverlandPath": true
  },
  {
    "Name": "Roaming Adventure Destinations",
    "Section": "Sites",
    "Count": 5,
    "Attributes": {
      "Primary": "Site",
      "Region": "{Theater.Region}"
    }
  },
  {
    "Name": "Regional Creature Hazards",
    "Section": "Hazards",
    "Count": 8,
    "Categories": {
      "Region Requirement": "{Theater.Region}"
    }
  }
]
