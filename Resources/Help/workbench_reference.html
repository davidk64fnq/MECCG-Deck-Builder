Modular Workbench Tab & Rules Reference

The Modular Deck Assembly Workbench (Deck > Assemble from Components... [Ctrl+M]) builds cohesive, tournament-legal Hero decks using a fixed 12-step pipeline across 13 tabs. Rather than drafting cards in isolation, each tab inspects what earlier steps placed into the deck—ensuring legal site paths, satisfied prerequisites, and zero dead cards.

Use this reference to see exactly which official database attributes, custom taxonomy categories, eligibility guards, and priority tiers each tab uses—and to understand why specific cards were (or were not) drafted.

1. General Settings

Pipeline Role: Orchestrator & Validation • Scope: Pool • Resources • Hazards • Sideboard • Sites

Configures global deck sizing, cycle assumptions, hazard targeting mode, and .workbench.json profile persistence, and runs the 12-step pipeline across all tabs.

Attributes & Categories Read

  • Official Attributes: Primary, Secondary, Race, and MPs (for the live composition breakdown and Marshalling Point readout).
  • Custom Categories: None directly; monitors status labels and checklist selections across all drafting tabs.

Coded Rules & Pipeline Logic

  • Hard Pre-Run Validation: Run Pipeline is disabled whenever a configuration violates hard tournament or budget limits:
    • Play Deck Size (20–60, default 30): Total configured Resources cards (characters + factions + allies + items + rings + palantíri + quests + environment events) or configured Hazards cards cannot exceed Play Deck Size.
    • Sideboard Size (0–30, default 20): Total configured Sideboard cards across all tabs cannot exceed Sideboard Size.
    • Character & Copy Caps: Play Deck characters ≤ 10; The One Ring ≤ 1; Nazgûl ≤ 9; Gates of Morning ≤ 3; Doors of Night ≤ 3; Twilight ≤ 3 combined across Resources + Hazards + Sideboard.
    • Checklist Guards: Required checklists (such as Region Terrains and Site Holds on Regions & Sites, or Role Focus, Special Ring Role Focus, Species / Race Focus, and Keying Filters on active drafting tabs) cannot be left completely unchecked when cards governed by them are requested.
  • Decks Before Council (1–4, default 1): Sets the per-site tap capacity across Steps 4–9 (Factions, Allies, Items, Rings, Palantíri, and Quests). Each non-Haven site in Sites supports up to N site-tapping cards in Resources (1 per planned deck cycle, since tapped sites untap on deck exhaust), while Havens never tap and have unlimited capacity.
  • Tailor Hazards to current deck (default unchecked): Switches Steps 11–12 (Creatures and Hazard Events) between Unknown Opponent mode (manual keying filters) and Target Current Deck mode (keying against your drafted Sites, Pool, and Resources).
  • 25-Attempt Retry Loop: Clicking Run Pipeline clears all five deck sections and executes Steps 1–12 in sequence up to 25 times:
    • Stops immediately if Step 1 fails on attempt 1, or as soon as all 12 steps complete with zero ⚠ warnings.
    • If every attempt produces at least one ⚠ warning, keeps the latest run with the fewest warning tabs (without biasing toward larger site counts or multi-card packages).
    • If all 25 attempts hit a hard lock, runs one diagnostic pass displaying the blocking error message.
  • Live MP Summary: Sums non-Hazard MPs across Pool, Resources, Sideboard, and Sites. Parenthesized values like (2) or 4(6) are tracked as Base(Conditional) totals (with Resources always displaying Base(Conditional)).

2. Regions & Sites

Pipeline Step: Step 1 • Target Section: Sites • Card Scope: Region • Site

Establishes the playable Middle-earth geography before any character or resource step runs, drafting all four Hero Havens, a connected region cluster, and eligible adventure sites.

Attributes & Categories Read

  • Official Attributes: Primary (Region, Site), Site (Haven vs. adventure hold types), Region, Alignment, Name, Set.
  • Custom Categories: Adjacent Regions (builds Middle-earth's bidirectional border graph), Region Type (read from Region cards and propagated to Site cards).

Coded Rules & Selection Logic

  • Automatic Hero Havens: Always drafts Rivendell, Lórien, Grey Havens, and Edhellond, preferring Hero → Neutral printings.
  • Terrain Filtering & Seed Fallback: Only regions whose Region Type matches a checked item in Region Terrains are eligible. If a named Seed Region is excluded by checked terrains, BFS finds the shortest border path to the nearest allowed region and starts there with a ⚠ notice.
  • Cluster Search (50 trials for Random / 25 for named seed): Expands a contiguous border-to-border region cluster up to Region Count (4–12, default 5). Scores clusters highest when they hit Region Count and contain at least 1 and at most Max Adventure Sites (1–50, default 12) matching adventure sites.
  • Adventure Site Filtering & Cap: Drafts non-Haven sites inside the chosen cluster whose Site hold is checked in Site Holds and whose Region Type is checked in Region Terrains. If more than Max Adventure Sites match, a random subset up to the cap is kept. Duplicate titles in Sites are never added.

Warnings & Edge Cases

  • ⚠ Seed adjusted: Triggered if the named seed was excluded by Region Terrains.
  • ⚠ Region / Site Shortfall: Triggered if fewer than Region Count connected regions match checked terrains, or 0 adventure sites match checked holds inside the cluster.

3. Starting Company

Pipeline Step: Step 2 • Target Section: Pool • Card Scope: Character (Non-Avatar)

Fills up to five starting character slots (all defaulting to Mind >= 1) while strictly respecting the official 20-Mind starting company limit.

Attributes & Categories Read

  • Official Attributes: Primary == "Character", Secondary / Race (excludes Avatars: Avatar, Wizard, Ringwraith), Skill, Race, Mind, Direct, Home, Name, Set.
  • Custom Categories: Home Region.
  • Intentionally Ignored: Character Site Requirement tags are ignored here because starting characters deploy at Rivendell regardless of home-site recruitment restrictions (allowing Hobbits to start in Pool without Bag End in Sites).

Coded Rules & Priority Tiers

  • Minimum Mind Feasibility Check: Before searching, sums the lowest Mind candidate for each active row; if the minimum sum exceeds 20, the step stops immediately.
  • 3-Tier Geographic Priority:
    1. Tier 1 (Local Region Group): Characters whose Home Region, home site's Region, or Home site/predicate matches the drafted regions in Sites or a Haven located inside those drafted regions.
    2. Tier 2 (Outside Havens): Characters homed at Havens outside the drafted region cluster.
    3. Tier 3 (Out-of-Region): Any remaining matching non-Avatar character.
  • 100-Attempt Permutation Search: Shuffles row assignment order across up to 100 attempts to find a distinct-character combination totaling ≤ 20 Mind with the highest Tier 1 / Tier 2 score, never duplicating titles across Pool, Resources, or Sideboard.

4. Wizards & Recruits

Pipeline Step: Step 3 • Target Sections: Resources • Sideboard • Card Scope: Character (Avatar & Non-Avatar)

Drafts tournament-legal Wizard (Avatar) configurations plus up to 10 Play Deck recruits and up to 3 Sideboard contingency characters.

Attributes & Categories Read

  • Official Attributes: Primary == "Character", Secondary == "Avatar", Race, Skill, Mind, Direct, Home, Unique, Name, Set.
  • Custom Categories: Home Region, Site Requirement (strictly enforced for non-Avatar recruits).

Coded Rules & Priority Tiers

  • Tournament Avatar Allowance: Supports 1–3 copies of Primary Wizard in Resources. When Primary < 3, a distinct Secondary Wizard (1–2 copies, capped so total Wizards ≤ 3) can be routed to Sideboard (default: Random 2 + Random 1) or Resources.
  • Recruit Site Requirement Guard: Unlike Starting Company, every recruit and Sideboard character must have its Site Requirement (if any) satisfied in Sites. For example, Hobbits (Site Requirement: Bag End) and Fram Framson (Site Requirement: Framsburg) only draft here if those sites are in the drafted Site deck.
  • 3-Tier Geographic Priority (25 attempts, tightest-row-first on attempt 0):
    1. Tier 1: Characters homed at drafted local adventure sites or Havens inside the drafted region group.
    2. Tier 2: Characters homed at Havens outside the drafted region group.
    3. Tier 3: Remaining Haven-playable characters (or those whose Site Requirement is met in Sites).
  • Uniqueness & Exclusion: Never drafts a character title already in Pool, and enforces Unique = 1 across non-Avatar recruits.

Warnings

  • ⚠ Emits a non-blocking notice if Saruman is drafted without Isengard in Sites, or Radagast without Rhosgobel (both still deploy normally at any Haven).

5. Factions

Pipeline Step: Step 4 • Target Sections: Resources • Sideboard • Card Scope: Resource (Faction)

Drafts Hero-playable factions strictly limited to sites present in the drafted Site deck, prioritizing character bonuses, species matches, and local geography while auto-drafting required prerequisite enablers.

Attributes & Categories Read

  • Official Attributes: Primary == "Resource", Secondary == "Faction", Alignment (Hero, Neutral, Dual, or blank), Race, Specific, Unique, Name, Set.
  • Custom Categories: Site Requirement (required), Prerequisite (; = OR branches, && = AND terms), and Faction Bonus (read from drafted characters).

Coded Rules & 4-Tier Ranking

  • Hard Eligibility Guards: Candidate must be Hero-playable, have a Site Requirement matched in Sites, satisfy Specific (if set) against drafted characters (Pool + Resources + Sideboard), and pass recursive prerequisite verification (each prerequisite in the chosen Prerequisite branch must also satisfy its own Site Requirement and Specific).
  • 4-Tier Priority Order:
    1. Tier 1: Matches a drafted character's Faction Bonus tag (ignoring wildcards * and All) OR matches a drafted character via Specific (such as Army of the Dead with Aragorn II), tie-broken by Pool > Resources > Sideboard.
    2. Tier 2: Matches a drafted character's Race (Pool > Resources > Sideboard).
    3. Tier 3: Playable at a local adventure site or local Haven inside the drafted region group.
    4. Tier 4: Remaining eligible factions (such as those at outside Havens).
  • Auto-Drafting & Copy Limits: Drafts Resources before Sideboard (variety-first, enforcing Unique = 1 / non-unique = 3 combined). Missing Prerequisite cards (e.g. Paths of the Dead) are automatically added to the same section if capacity allows.
  • Per-Cycle Site-Capacity Matching: Pass 1 enforces Decks Before Council tap capacity across non-Haven sites in Sites (1 Resources play per cycle; Havens unlimited), factoring in any site-tapping Prerequisite cards. If no within-capacity faction exists, Pass 2 falls back and logs a ⚠ warning.

6. Allies

Pipeline Step: Step 5 • Target Sections: Resources • Sideboard • Card Scope: Resource (Ally)

Drafts Hero-playable allies playable at drafted Sites or Havens, prioritizing local territory and preventing 1-deck site bottlenecks with Resources Factions.

Attributes & Categories Read

  • Official Attributes: Primary == "Resource", Secondary == "Ally", Alignment (Hero, Neutral, Dual), Specific, Unique, Name, Set.
  • Custom Categories: Site Requirement (required), Prerequisite.

Coded Rules & Priority Tiers

  • Hard Eligibility Guards: Must be Hero-playable, satisfy Specific against drafted characters, have a Site Requirement matched in Sites, and pass recursive Prerequisite chain checks (auto-drafting missing prerequisites into the same section).
  • 2-Tier Geographic Priority:
    1. Tier 1: Playable at local adventure sites or local Havens inside the drafted region group.
    2. Tier 2: Playable at Havens outside the drafted region group.
  • Per-Cycle Site-Capacity Matching: Pass 1 uses capacitated bipartite matching across all site-tapping cards already in Resources (allowing up to Decks Before Council cards per non-Haven site in Sites, and unlimited plays at Havens). If no within-capacity ally exists, Pass 2 falls back to an over-capacity ally and logs a ⚠ warning naming the site(s) and conflicting card(s).

7. Items

Pipeline Step: Step 6 • Target Sections: Pool (Minor) • Resources • Sideboard • Card Scope: Resource (Standard & Non-Ring/Non-Palantír Special Items)

Drafts Minor, Major, Greater, and non-specialized Special Items using flat hard eligibility guards and checked Role Focus filters.

Attributes & Categories Read

  • Official Attributes: Primary == "Resource", Secondary (Minor Item, Major Item, Greater Item, Special Item), Alignment, Race (detects Scroll for site playability; excludes Palantír), MinorItem, MajorItem, GreaterItem, Scroll, Hoard, Specific, Unique.
  • Custom Categories: Role (filtered by Role Focus), Site Requirement, Region Requirement, Prerequisite, Target Species.

Exclusions & Cross-Tab Interactions

  • Reserved Item Exclusions: Excludes Gold Ring Item cards, Ring Special Item cards (The One Ring, Dwarven, Magic, Lesser, Wizard's Ring), Palantír items, and any item tagged Role: Quest (such as Book of Mazarbul or Sapling of the White Tree), leaving them to the Rings, Palantíri, and Quests tabs.
  • Scroll of Isildur: Drafts as a Greater Item on this tab (playable at GreaterItem = yes or Scroll = yes sites such as Tolfalas) and is automatically counted toward Aid Ring Test on the Rings tab.

Coded Rules & Hard Guards

  • Draft Order: Pool Minor Items (0–2, capped by Pool character count; skips site check because starting items deploy with the starting company) → Special → Greater → Major → Minor (Resources before Sideboard), variety-first.
  • Eligibility Guards:
    • Must carry at least one checked Role tag under Role Focus.
    • Region Requirement (if tagged) must match a drafted Region name or Region Type.
    • Site Requirement (if tagged) must match Sites; otherwise standard-tier items require a site with the matching MinorItem / MajorItem / GreaterItem / Scroll flag (and Hoard = yes on the same site when the item has Hoard = yes).
    • Specific (if set) must match a drafted character; Prerequisite (if tagged) must already exist in Pool + Resources + Sideboard (this tab does not auto-draft missing prerequisites).
    • Target Species is enforced only for Hero character races (Dúnadan, Dwarf, Elf, Hobbit, Man, Wizard). Creature-targeted tags (such as Orc on Glamdring or Animal; Spider; Undead; Wolf on Star-glass) are ignored here.
  • Per-Cycle Site-Capacity Matching: For Resources items, Pass 1 runs across all four tiers (Special → Greater → Major → Minor) within remaining Decks Before Council non-Haven site capacity before Pass 2 fills any shortfall with a ⚠ warning. Pool starting Minor Items (deployed at Rivendell before Turn 1) and Sideboard items are unrestricted.

8. Rings

Pipeline Step: Step 7 • Target Sections: Resources • Sideboard • Card Scope: Gold Rings • Ring Special Items • Ring Test Cards

Drafts coordinated Gold Ring packages—scoring Gold Ring roll tables for desired Special Rings and counting existing ring-testing abilities already in the deck.

Attributes & Categories Read

  • Official Attributes: Primary == "Resource", Secondary (Gold Ring Item, Special Item, *event*, or standard item tier), Alignment, Text (2d6 roll-table parsing), Race, Skill, GoldRing, Specific, Unique, Name.
  • Custom Categories: Special Ability (Gold Ring: Allow Test, Gold Ring: Aid Test, Gold Ring: Exclude One Ring), Role (filtered by Special Ring Role Focus), Site Requirement, Region Requirement, Prerequisite, Target Species.

Coded Rules & Cross-Tab Interactions

  • GoldRing = yes Site Gate: Gold Rings, Ring Tests, The One Ring, Dwarven Rings, Magic Rings, and Lesser Rings require at least one GoldRing = yes site in Sites. If none exists, those slots are skipped with a ⚠ warning. (Wizard's Ring only requires a Haven via Site Requirement plus a Wizard in the deck.)
  • 2d6 Roll-Table Scoring: When any Special Ring (One, Dwarven, or Magic) is requested, Gold Rings are scored by parsing their printed 2d6 outcomes in Text (5 × One Ring ways + 2 × Dwarven Ring ways + 1 × Magic/Spirit Ring ways) and drafted playset-first. Otherwise, Gold Rings draft variety-first.
  • Total Test Counting & Ringlore Exclusion: Allow Ring Test and Aid Ring Test spinners represent totals. Cards already drafted in earlier tabs (such as Gandalf for Gold Ring: Allow Test, counted at most once per unique title per section, or Scroll of Isildur from Items for Gold Ring: Aid Test) are counted first before drafting additional test events. If The One Ring is requested without other tested Special Rings in that section, testers tagged Gold Ring: Exclude One Ring (Ringlore) are excluded; otherwise they are ranked behind unrestricted testers.
  • Special Ring Guards: The One Ring is capped at ≤ 1 combined (Resources + Sideboard). Dwarven Rings do not enforce Target Species: Dwarf (any character can bear them). Non-One Special Rings must pass checked tags in Special Ring Role Focus. All cards check Region Requirement, Site Requirement, Specific, existing Prerequisite, and Skill/Race locks.
  • Per-Cycle Site-Capacity Matching: Resources Gold Rings run Pass 1 within remaining Decks Before Council capacity across non-Haven GoldRing = yes sites before Pass 2 fills any shortfall with a ⚠ warning. Special Rings (which replace Gold Rings on test, or play at a Haven for Wizard's Ring) and Ring Test events do not consume site tap slots.

9. Palantíri

Pipeline Step: Step 8 • Target Sections: Resources • Sideboard • Card Scope: Palantír Items & Palantír Use Events

Drafts Palantír seeing stones playable at drafted sites and ensures activation support while crediting innate user abilities already in the deck.

Attributes & Categories Read

  • Official Attributes: Primary == "Resource", Race == "Palantír", Alignment, Skill (Sage), GreaterItem, Palantiri, Hoard, Specific, Unique, Name.
  • Custom Categories: Special Ability (Palantír: Allow Use), Role (filtered by Role Focus), Site Requirement, Region Requirement, Prerequisite, Target Species.

Coded Rules & Guards

  • Palantír Item Playability: A Palantír is eligible if its Site Requirement (e.g., Isengard, Minas Tirith, The White Towers) matches Sites, or—when no Site Requirement is tagged—if Sites contains a location with GreaterItem = yes or Palantiri = yes (such as Lossadan Cairn, respecting Hoard).
  • Item Guards: Enforces checked Role Focus tags, Region Requirement, Specific, existing Prerequisite, Skill, and Target Species (Palantír of Elostirion requires an Elf or Wizard in the deck).
  • Total Allow Palantír Use Counting: Counts existing Special Ability: Palantír: Allow Use cards in Resources / Sideboard (such as Saruman, counted once per unique title) before drafting Align Palantír or Use Palantír (which require a Sage).
  • Per-Cycle Site-Capacity Matching: Resources Palantír items run Pass 1 within remaining Decks Before Council non-Haven site capacity (avoiding collisions with earlier Factions, Allies, or Items on sites like Minas Tirith or Isengard) before Pass 2 falls back with a ⚠ warning.

10. Quests

Pipeline Step: Step 9 • Target Sections: Resources • Sideboard • Card Scope: Resource (Role = Quest Events & Quest Items)

Drafts storyline objectives (both events and Quest Special Items), prioritizing quests whose prerequisites are already present and optionally bundling the One Ring package.

Attributes & Categories Read

  • Official Attributes: Primary == "Resource", Secondary, Alignment, Skill, Specific, Unique, GoldRing, discrete item flags (for Quest items without explicit Site Requirement), Name.
  • Custom Categories: Role (Quest plus secondary roles / Quest (Only)), Prerequisite (; = OR, && = AND), Site Requirement (supports && multi-site clauses such as Bag End && Lórien), Region Requirement, Target Species, Special Ability.

Coded Rules & Priority Tiers

  • Role Focus (Quest (Only) vs. Hybrid Quests): Pure Quests carrying only Role: Quest match Quest (Only); Quests carrying additional Role tags match if any of those secondary roles is checked.
  • Eligibility Guards: Enforces Region Requirement, Site Requirement (all terms in && clauses must exist in Sites), Specific, Skill/Race, and Target Species (e.g., Dúnadan on Andúril, the Flame of the West, Hobbit on Red Book of Westmarch).
  • 2-Tier Prerequisite Resolution: Evaluates Prerequisite branches recursively, selecting the branch needing the fewest new cards:
    1. Tier 1 (Already Satisfied): Quests whose Prerequisite is already in the deck (0 extra cards needed).
    2. Tier 2 (Standalone / Self-Contained): Quests with no Prerequisite, or Quests whose missing prerequisite cards pass all guards and fit in remaining section capacity (auto-drafted into the same section).
  • Optional One Ring Package (Auto-draft One Ring package): When checked and a Quest requires The One Ring (Cracks of Doom, Gollum's Fate) that is not yet in the deck, checks for a GoldRing = yes site in Sites and automatically bundles The One Ring, an optimal Gold Ring (if missing), and an unrestricted Gold Ring: Allow Test card (excluding Gold Ring: Exclude One Ring, and accounting for prior Special Rings consuming single-use Short-event testers).
  • Per-Cycle Site-Capacity Matching: Pass 1 checks Quest Items and any site-tapping Prerequisite cards (such as factions or an auto-drafted Gold Ring) against remaining Decks Before Council non-Haven site capacity in Resources; if capacity is exhausted, Pass 2 falls back and logs a ⚠ warning.

11. Resource Events

Pipeline Step: Step 10 • Target Sections: Resources • Sideboard • Card Scope: Resource (Events & Twilight)

Drafts requested environment cards (Gates of Morning and Twilight), then auto-fills all remaining Play Deck capacity up to Play Deck Size (plus requested Sideboard events) across checked Role Focus tags.

Attributes & Categories Read

  • Official Attributes: Primary == "Resource", Secondary (contains "event"), Alignment, Skill, Specific, Unique, Name (Gates of Morning, Twilight).
  • Custom Categories: Role (filtered by Role Focus), Site Requirement, Region Requirement, Prerequisite, Target Species.

Exclusions & Coded Rules

  • Reserved Exclusions: Excludes Gates of Morning, Twilight, Role = Quest events, Gold Ring: Allow Test events, and Palantír: Allow Use events from the general auto-fill pool so earlier tabs and the environment spinners remain authoritative.
  • Environment Cards First: Drafts requested Gates of Morning (≤ 3) and Twilight (preferring Neutral printing; ≤ 3 combined across the entire deck) before auto-fill runs.
  • Proportionate Role Allocation: Computes eligible events passing all guards (Role Focus, Region Requirement, Site Requirement, Specific, existing Prerequisite in Pool + Resources + Sideboard, Skill/Race, and Target Species). Allocates slots proportionately to the number of eligible cards in each checked Role (guaranteeing at least 1 per eligible role when enough slots exist), drafting narrowest roles first with variety-first copy selection.

12. Creatures

Pipeline Step: Step 11 • Target Sections: Hazards • Sideboard • Card Scope: Nazgûl • Nazgûl Support • Standard & Dual-Mode Creatures

Drafts Hazard creatures and Nazgûl packages while tracking tournament creature equivalents (Standard + (Nazgûl + Dual) / 2 >= 12) and adapting keying rules to the global Tailor Hazards to current deck toggle.

Attributes & Categories Read

  • Official Attributes: Primary == "Hazard", Secondary (Creature, Creature/*event*), Alignment, Race (Nazgûl and checked items in Species / Race Focus), Unique, Name.
  • Custom Categories: Target Species (Nazgûl for Nazgûl Support), Region Requirement, Site Requirement, Region Type.

Draft Order & Proportionate Species Bucketing

  • Execution Order (Hazards before Sideboard):
    1. Nazgûl (0.5 equiv): Race = Nazgûl (≤ 9 combined). In Target Current Deck mode, prioritizes creature-keyable Nazgûl over permanent-event-only Nazgûl.
    2. Nazgûl Support: Non-Nazgûl Hazard events carrying Target Species: Nazgûl.
    3. Standard Creatures (1.0 equiv): Secondary == "Creature", distributed proportionately across checked Species / Race Focus buckets with variety-first sampling.
    4. Dual-Mode Half-Creatures (0.5 equiv): Non-Nazgûl cards whose Secondary contains both Creature and event (such as Shelob or Mouth of Sauron), also bucketed proportionately by checked species.

Targeting Mode Behavior (Controlled on General Settings)

13. Hazard Events

Pipeline Step: Step 12 • Target Sections: Hazards • Sideboard • Card Scope: Hazard (Events & Twilight)

Drafts requested Hazard environment cards (Doors of Night and Twilight), then auto-fills remaining Play Deck capacity up to Play Deck Size (plus requested Sideboard events) across checked Role Focus tags.

Attributes & Categories Read

  • Official Attributes: Primary == "Hazard", Secondary (contains "event"; checks Long-event for Duration), Alignment, Specific, Unique, Name (Doors of Night, Twilight).
  • Custom Categories: Role (filtered by Role Focus), Region Requirement, Site Requirement, Target Item, Target Species, Prerequisite, Automatic Attack, Region Type.

Exclusions & Coded Rules

  • Reserved Exclusions: Excludes Doors of Night, Twilight, and all cards belonging to Step 11 (Creatures: Nazgûl, Nazgûl Support, Standard Creatures, and Dual-Mode Creatures).
  • Shared Twilight Cap: Drafts Doors of Night (≤ 3) and Twilight first; Twilight strictly shares a single 3-copy limit across Resources + Hazards + Sideboard.
  • Proportionate Role Auto-Fill & Duration Gate: Distributes remaining Hazards and Sideboard event slots proportionately across checked Role Focus buckets with variety-first sampling. Events tagged Role: Duration (The Will of Sauron) are held in the last bucket and are only drafted if at least one Hazard Long-event is already present in Hazards + Sideboard.
