Modular Workbench Tab & Rules Reference

The Modular Deck Assembly Workbench (Deck > Assemble from Components... [Ctrl+M]) builds cohesive, tournament-legal Hero decks using a fixed 12-step pipeline navigated from a left-hand sidebar (General Settings plus Steps 1–12). Rather than drafting cards in isolation, each step inspects what earlier steps placed into the five deck sections—Pool (main window Pool tab), Resources (Res tab), Hazards (Haz tab), Sideboard (Side tab), and Sites (Site tab)—ensuring legal site paths, satisfied prerequisites, and zero dead cards.

Use this reference to see exactly which official database attributes, custom taxonomy categories, eligibility guards, and priority tiers each step uses—and to understand why specific cards were (or were not) drafted.

General Settings

Pipeline Role: Orchestrator & Validation • Scope: Pool • Resources • Hazards • Sideboard • Sites

Configures global deck sizing, cycle assumptions, hazard targeting mode, and .workbench.json profile persistence (plus Reset Defaults), and runs the 12-step pipeline across all tabs.

Attributes & Categories Read

  • Official Attributes: Primary, Secondary, Race, and MPs (for the live composition breakdown and Marshalling Point readout).
  • Custom Categories: None directly; monitors status labels and checklist selections across all drafting tabs.

Coded Rules & Pipeline Logic

  • Hard Pre-Run Validation: Run Pipeline is disabled whenever a configuration violates hard tournament or budget limits:
    • Play Deck Size (20–60, default 30): Total configured Resources cards (characters + factions + allies + items + rings + palantíri + quests + environment events) or configured Hazards cards cannot exceed Play Deck Size.
    • Sideboard Size (0–30, default 20): Total configured Sideboard cards across all tabs cannot exceed Sideboard Size.
    • Character & Copy Caps: Play Deck non-Avatar characters ≤ 10; Avatars ≤ 3 (up to 2 distinct Wizards across Resources + Sideboard); The One Ring ≤ 1; Nazgûl ≤ 9; Gates of Morning ≤ 3; Doors of Night ≤ 3; Twilight ≤ 3 combined across Resources + Hazards + Sideboard.
    • Checklist Guards: Required checklists (such as Region Terrains and Site Holds on the Regions & Sites tab, or Role, Special Ring Role, Creature Race, and Keying Filters on active drafting tabs) cannot be left completely unchecked when cards governed by them are requested.
  • Decks Before Council (1–4, default 1): Sets the per-site tap capacity across Steps 4–9 (Factions, Allies, Rings, Palantíri, Items, and Quests tabs). Each non-haven site in Sites supports up to N site-tapping cards in Resources (1 per planned deck cycle, since tapped sites untap on deck exhaust), while havens never tap and have unlimited capacity. Any Pass 2 overflow emits one grouped ⚠ warning per contested site bottleneck (showing a Shared site pool line when earlier tabs share sites with the current tab).
  • Tailor Hazards to current deck (default unchecked): Switches Steps 11–12 (Creatures and Hazard Events tabs) between Unknown Opponent mode (manual keying filters) and Target Current Deck mode (keying against your drafted Sites, Pool, and Resources).
  • 25-Attempt Retry Loop: Clicking Run Pipeline (F5) (or pressing F5 from any workbench tab) clears all five deck sections and executes Steps 1–12 in sequence up to 25 times:
    • Stops immediately if Step 1 fails on attempt 1, or as soon as all 12 steps complete with zero ⚠ warnings.
    • If every attempt produces at least one ⚠ warning, keeps the latest run with the fewest warning tabs (without biasing toward larger site counts or multi-card packages).
    • If all 25 attempts hit a hard lock, runs one diagnostic pass displaying the blocking error message.
  • Live MP Summary: Sums non-Hazard MPs across Pool, Resources, Sideboard, and Sites. Parenthesized values like (2) or 4(6) are tracked as Base(Conditional) totals (with Resources always displaying Base(Conditional)).

1. Regions & Sites

Pipeline Step: Step 1 • Target Section: Sites • Card Scope: Region • Site

Establishes the playable Middle-earth geography before any character or resource step runs, drafting all four Hero havens, a connected region group, and eligible sites.

Attributes & Categories Read

  • Official Attributes: Primary (Region, Site), Site (Haven vs. site hold types), Region, Alignment, Name, Set.
  • Custom Categories: Adjacent Regions (used to build a map of the regions), Region Type.

Coded Rules & Selection Logic

  • Automatic Hero havens: Always drafts Rivendell, Lórien, Grey Havens, and Edhellond.
  • Terrain & Seed Filtering: Only regions whose Region Type matches a checked item in Region Terrains are listed in the Seed Region dropdown and eligible for drafting. If an already-selected or profile-loaded Seed Region becomes excluded by unchecking its terrain, it remains selected with a ⚠ validation error and disables Run Pipeline until its terrain is re-checked or another seed is chosen.
  • Region group must contain a haven (unchecked by default): When checked, requires the drafted region group to include at least one Hero haven's region (Rivendell, Lórien, Grey Havens, or Edhellond) reachable through checked Region Terrains within Region Count regions (counting both the seed and the haven region). If no haven region matches checked terrains, or if a named Seed Region needs more than Region Count regions to reach one, Run Pipeline is disabled with a ⚠ validation error.
  • Region Group Search (50 trials): Builds a region group—where every region shares a border with at least one other region in the group—up to Region Count (4–12, default 5). Stops on the first group that hits Region Count with 1 to Max Sites (1–50, default 12) matching sites—or, if every roll exceeds the cap, keeps a random group and trims its sites randomly to Max Sites.
  • Site Filtering & Cap: Drafts sites inside the chosen region group whose Site hold is checked in Site Holds and whose Region Type is checked in Region Terrains. If more than Max Sites match, a random subset up to the cap is kept. Duplicate titles in Sites are never added.

Warnings & Edge Cases

  • ⚠ Seed terrain mismatch: Triggered when a selected or profile-loaded Seed Region's Region Type is unchecked in Region Terrains (disables Run Pipeline until resolved).
  • ⚠ Haven unreachable: Triggered when Region group must contain a haven is checked and either no Hero haven's region matches Region Terrains, or a named Seed Region cannot reach an allowed haven region within Region Count (disables Run Pipeline until resolved).
  • ⚠ Region / Site Shortfall: Triggered if fewer than Region Count connected regions match checked terrains, or 0 sites match checked holds inside the region group.

2. Starting Company

Pipeline Step: Step 2 • Target Section: Pool • Card Scope: Character (Non-Avatar)

Fills up to five starting character slots (defaulting to Mind >= 1 and DI <= 4) while strictly respecting the official 20-Mind starting company limit.

Attributes & Categories Read

  • Official Attributes: Primary (Character), Secondary (Character — non-Avatar), Skill, Race, Mind, Direct (blank treated as 0 for non-Avatar characters), Home, Name, Set.
  • Custom Categories: Home Region.
  • Intentionally Ignored: Character Site Requirement tags are ignored here because starting characters deploy at Rivendell regardless of home-site recruitment restrictions (allowing Hobbits to start in Pool without Bag End in Sites).

Coded Rules & Priority Tiers

  • Row & Mind Validation: On exiting a Mind or DI box (or changing Skill Focus / Species / Race), checks that every active row matches at least one character in active sets and that the lowest Mind sum across active rows is <= 20; otherwise disables Run Pipeline with a warning.
  • Geographic Priority:
    • Tier 1 (Local Region Group): Characters whose home site is in one of the drafted regions (including any haven inside those regions).
    • Tier 2 (Other Eligible): Any remaining matching character.
  • Company Assembly Search: Runs 100 trials to find a company matching the requirements, selecting the combination with the most Tier 1 matches and breaking remaining ties randomly, without duplicating titles across Pool, Resources, or Sideboard.

3. Wizards & Recruits

Pipeline Step: Step 3 • Target Sections: Resources • Sideboard • Card Scope: Character (Avatar & Non-Avatar)

Drafts tournament-legal Wizard (Avatar) configurations plus up to 10 Play Deck recruits and up to 3 Sideboard contingency characters.

Attributes & Categories Read

  • Official Attributes: Primary (Character), Secondary (Avatar for Wizards; Character — non-Avatar for recruits), Race, Skill, Mind, Direct (blank treated as 0 for non-Avatar characters), Home, Unique, Name, Set.
  • Custom Categories: Home Region, Site Requirement (strictly enforced for non-Avatar recruits).

Coded Rules & Priority Tiers

  • Tournament Avatar Allowance: Supports 1–3 copies of Primary Wizard in Resources. When Primary Wizard has fewer than 3 copies, a distinct Secondary Wizard (1–2 copies, capped at 3 Wizards total) can be routed to either Sideboard or Resources. By default, 2 copies of a random Primary Wizard go to Resources and 1 copy of a distinct random Secondary Wizard goes to Sideboard.
  • Row Validation: On exiting a Mind or DI box (or changing Skill Focus / Species / Race) on any Play Deck Characters or Sideboard Characters row, checks that the row matches at least one non-Avatar character in active sets; otherwise disables Run Pipeline with a warning.
  • Recruit Site Requirement Guard: Unlike the Starting Company tab, every recruit and Sideboard character must have its Site Requirement (if any) satisfied in Sites. For example, Hobbits (Site Requirement: Bag End) and Fram Framson (METD; Site Requirement: Framsburg) only draft here if those sites are in the drafted Site deck.
  • Geographic Priority:
    • Tier 1 (Drafted Sites & Local Havens): Characters whose home site is a drafted site or a haven inside the drafted region group.
    • Tier 2 (Other Eligible): Any remaining matching character (whose Site Requirement, if any, is satisfied in Sites).
  • Recruit Assembly Search: Runs 100 trials to fill all rows without duplicating unique characters across Pool, Resources, and Sideboard, selecting the combination with the most Tier 1 matches and breaking remaining ties randomly.
  • Wizard Home Site Note: Displays an informational note (not a warning) if Saruman is drafted without Isengard in Sites, or Radagast without Rhosgobel (both deploy normally at any haven).

4. Factions

Pipeline Step: Step 4 • Target Sections: Resources • Sideboard • Card Scope: Resource (Faction)

Drafts Hero-playable factions strictly limited to sites present in the drafted Site deck, prioritizing character bonuses, species matches, and local geography while auto-drafting required prerequisite enablers, plus optional Role (Faction Support) influence-boosting events.

Attributes & Categories Read

  • Official Attributes: Primary (Resource), Secondary (Faction, plus events for Faction Support), Alignment (Hero, Neutral, Dual, or blank), Race, Skill, Specific, Unique, Name, Set.
  • Custom Categories: Site Requirement (required for factions), Prerequisite (; = OR branches, && = AND terms), Faction Bonus (read from drafted characters), Role (Faction Support), Region Requirement, Target Species.

Coded Rules & 4-Tier Ranking

  • Hard Eligibility Guards: Candidate must be Hero-playable, have a Site Requirement matched in Sites, satisfy Specific (if set) against drafted characters (Pool + Resources + Sideboard), and have any required Prerequisite cards (and anything those cards require) also satisfy their own Site Requirement and Specific checks.
  • 4-Tier Priority Order:
    1. Tier 1: Matches a drafted character's Faction Bonus tag or matches a drafted character via Specific (such as Army of the Dead with Aragorn II), tie-broken by Pool > Resources > Sideboard.
    2. Tier 2: Matches a drafted character's Race (Pool > Resources > Sideboard).
    3. Tier 3: Playable at a local site or local haven inside the drafted region group.
    4. Tier 4: Remaining eligible factions (such as those at outside havens).
  • Auto-Drafting & Copy Limits: Drafts Resources before Sideboard (variety-first, enforcing Unique = 1 / non-unique = 3 combined). Missing Prerequisite cards (e.g., Paths of the Dead) are automatically added to the same section if capacity allows.
  • Per-Cycle Site-Capacity Matching: Prefers factions (including any site-tapping Prerequisite cards) that fit within Decks Before Council tap capacity across non-haven sites in Sites (1 Resources play per cycle; havens unlimited). If none fit within remaining capacity, it still drafts an eligible faction and logs a ⚠ warning.
  • Faction Support (Events): Drafted after Factions (using remaining Resources/Sideboard capacity) from Hero-playable Resource events tagged Role: Faction Support, enforcing Skill/Race, Target Species, Specific, Site Requirement, Region Requirement, and existing Prerequisite cards.

5. Allies

Pipeline Step: Step 5 • Target Sections: Resources • Sideboard • Card Scope: Resource (Ally)

Drafts Hero-playable allies playable at drafted sites or havens, prioritizing local territory and preventing 1-deck site bottlenecks with Resources Factions.

Attributes & Categories Read

  • Official Attributes: Primary (Resource), Secondary (Ally), Alignment (Hero, Neutral, Dual, or blank), Specific, Unique, Name, Set.
  • Custom Categories: Site Requirement (required), Prerequisite.

Coded Rules & Priority Tiers

  • Hard Eligibility Guards: Must be Hero-playable, satisfy Specific against drafted characters, have a Site Requirement matched in Sites, and have any required Prerequisite cards (and anything those cards require) also satisfy their own Site Requirement and Specific checks (auto-drafting missing prerequisites into the same section if capacity allows).
  • 2-Tier Geographic Priority:
    1. Tier 1: Playable at local sites or local havens inside the drafted region group.
    2. Tier 2: Playable at havens outside the drafted region group.
  • Per-Cycle Site-Capacity Matching: Prefers allies (including any site-tapping Prerequisite cards) that fit within Decks Before Council tap capacity across non-haven sites in Sites alongside all site-tapping cards already in Resources (1 Resources play per cycle; havens unlimited). If none fit within remaining capacity, it still drafts an eligible ally and logs a grouped ⚠ warning naming the contested site(s) and blocking card(s).

6. Rings

Pipeline Step: Step 6 • Target Sections: Resources • Sideboard • Card Scope: Gold Rings • Ring Special Items • Ring Test Cards

Drafts coordinated Gold Ring packages—scoring Gold Ring roll tables for desired Special Rings, drafting before Items so scarce GoldRing = yes sites are reserved first, and counting existing ring-testing abilities already in the deck.

Attributes & Categories Read

  • Official Attributes: Primary (Resource), Secondary (Gold Ring Item, Special Item, events, or standard item tiers), Alignment (Hero, Neutral, Dual, or blank), Text (2d6 roll-table parsing), Race, Skill, GoldRing (yes), Specific, Unique, Name, Set.
  • Custom Categories: Special Ability (Gold Ring: Allow Test, Gold Ring: Aid Test, Gold Ring: Exclude One Ring), Role (filtered by Special Ring Role), Site Requirement, Region Requirement, Prerequisite, Target Species.

Coded Rules & Cross-Tab Interactions

  • GoldRing = yes Site Gate: Gold Rings, Ring Tests, The One Ring, Dwarven Rings, Magic Rings, and Lesser Rings require at least one GoldRing = yes site in Sites. If none exists, those slots are skipped with a ⚠ warning. (Wizard's Ring only requires a haven via Site Requirement plus a Wizard in the deck.)
  • 2d6 Roll-Table Scoring: When any Special Ring (One, Dwarven, or Magic) is requested, Gold Rings are scored by parsing their printed 2d6 outcomes in Text (5 × One Ring ways + 2 × Dwarven Ring ways + 1 × Magic/Spirit Ring ways) and drafted playset-first. Otherwise, Gold Rings draft variety-first.
  • Total Test Counting & Ringlore Exclusion: The Allow Ring Test and Aid Ring Test spinners represent totals. Cards already drafted in earlier tabs (such as Gandalf for Gold Ring: Allow Test, counted at most once per unique title per section) are counted first before drafting additional test cards, and Aid Ring Test drafts Scroll of Isildur directly here ahead of the Items tab. If The One Ring is requested without other tested Special Rings in that section, testers tagged Gold Ring: Exclude One Ring (Ringlore) are excluded; otherwise they are ranked behind unrestricted testers.
  • Special Ring Guards: The One Ring is capped at ≤ 1 combined (Resources + Sideboard). Dwarven Rings do not enforce Target Species: Dwarf (any character can bear them). Non-One Special Rings must pass checked tags in Special Ring Role. All cards check Region Requirement, Site Requirement, Specific, existing Prerequisite, and Skill/Race locks.
  • Per-Cycle Site-Capacity Matching: Resources Gold Rings and site-tapping Aid Ring Test items (Scroll of Isildur) run Pass 1 within remaining Decks Before Council non-haven site capacity before Pass 2 fills any shortfall with a grouped ⚠ warning (including a Shared site pool breakdown if earlier steps share sites). Special Rings (which replace Gold Rings on test, or play at a haven for Wizard's Ring) and Ring Test events do not consume site tap slots.

7. Palantíri

Pipeline Step: Step 7 • Target Sections: Resources • Sideboard • Card Scope: Palantír Items & Palantír Use Events

Drafts Palantír seeing stones playable at drafted sites and ensures activation support while crediting innate user abilities already in the deck.

Attributes & Categories Read

  • Official Attributes: Primary (Resource), Race (Palantír), Alignment (Hero, Neutral, Dual, or blank), Skill (Sage), GreaterItem (yes), Palantiri (yes), Hoard (yes), Specific, Unique, Name, Set.
  • Custom Categories: Special Ability (Palantír: Allow Use), Role (filtered by Role), Site Requirement, Region Requirement, Prerequisite, Target Species.

Coded Rules & Guards

  • Palantír Item Playability: A Palantír is eligible if its Site Requirement (e.g., Isengard, Minas Tirith, The White Towers) matches Sites, or—when no Site Requirement is tagged—if Sites contains a location with GreaterItem = yes or Palantiri = yes (such as Lossadan Cairn, respecting Hoard).
  • Item Guards: Enforces checked Role tags, Region Requirement, Specific, existing Prerequisite, Skill, and Target Species (Palantír of Elostirion requires an Elf or Wizard in the deck).
  • Total Allow Palantír Use Counting: Counts existing Special Ability: Palantír: Allow Use cards in Resources / Sideboard (such as Saruman, counted once per unique title) before drafting Align Palantír or Use Palantír (which require a Sage).
  • Per-Cycle Site-Capacity Matching: Running ahead of Items gives Palantíri priority on scarce GreaterItem / Palantiri site slots. Resources Palantír items run Pass 1 within remaining Decks Before Council non-haven site capacity (avoiding collisions with earlier Factions, Allies, or Rings) before Pass 2 falls back with a grouped ⚠ warning.

8. Items

Pipeline Step: Step 8 • Target Sections: Pool (Minor) • Resources • Sideboard • Card Scope: Resource (Standard & Non-Ring/Non-Palantír Special Items)

Drafts Minor, Major, Greater, and non-specialized Special Items using flat hard eligibility guards and checked Role filters, running after Rings and Palantíri so Pass 1 steers around sites already claimed by Gold Rings and Palantíri.

Attributes & Categories Read

  • Official Attributes: Primary (Resource), Secondary (Minor Item, Major Item, Greater Item, Special Item), Alignment (Hero, Neutral, Dual, or blank), Race (detects Scroll for site playability; excludes Palantír), MinorItem (yes), MajorItem (yes), GreaterItem (yes), Scroll (yes), Hoard (yes), Specific, Unique, Name, Set.
  • Custom Categories: Role (filtered by Role), Site Requirement, Region Requirement, Prerequisite, Target Species.

Exclusions & Cross-Tab Interactions

  • Reserved Item Exclusions: Excludes Gold Ring Item cards, Ring Special Item cards (The One Ring, Dwarven, Magic, Lesser, Wizard's Ring), Palantír items, and any item tagged Role: Quest (such as Book of Mazarbul or Sapling of the White Tree), leaving them to the Rings, Palantíri, and Quests tabs.
  • Scroll of Isildur: If Rings already drafted Scroll of Isildur for Aid Ring Test, Items skips duplicating it (since it is Unique) and picks another Greater Item; otherwise it remains eligible here as a Greater Item playable at GreaterItem = yes or Scroll = yes sites (such as Tolfalas).

Coded Rules & Hard Guards

  • Draft Order: Pool Minor Items (0–2, capped by Pool character count; skips site check because starting items deploy with the starting company) → Special Item → Greater Item → Major Item → Minor Item (Resources before Sideboard), variety-first.
  • Eligibility Guards:
    • Must carry at least one checked Role tag under Role.
    • Region Requirement (if tagged) must match a drafted Region name or Region Type.
    • Site Requirement (if tagged) must match Sites; otherwise standard-tier items require a site with the matching MinorItem / MajorItem / GreaterItem / Scroll flag (and Hoard = yes on the same site when the item has Hoard = yes).
    • Specific (if set) must match a drafted character; Prerequisite (if tagged) must already exist in Pool + Resources + Sideboard (this tab does not auto-draft missing prerequisites).
    • Target Species is enforced only for Hero character races (Dúnadan, Dwarf, Elf, Hobbit, Man, Wizard). Creature-targeted tags (such as Orc on Glamdring or Animal; Spider; Undead; Wolf on Star-glass) are ignored here.
  • Per-Cycle Site-Capacity Matching: For Resources items, Pass 1 runs across all four tiers (Special Item → Greater Item → Major Item → Minor Item) within remaining Decks Before Council non-haven site capacity—automatically preferring items playable at remaining open sites before Pass 2 fills any shortfall with a grouped ⚠ warning. Pool starting Minor Items (deployed at Rivendell before Turn 1) and Sideboard items are unrestricted.

9. Quests

Pipeline Step: Step 9 • Target Sections: Resources • Sideboard • Card Scope: Resource (Role = Quest Events & Quest Items)

Drafts storyline objectives (both events and Quest Special Items), prioritizing quests whose prerequisites are already present and optionally bundling the One Ring package.

Attributes & Categories Read

  • Official Attributes: Primary (Resource), Secondary (Gold Ring Item, Special Item, standard item tiers, events), Alignment (Hero, Neutral, Dual, or blank), Skill, Specific, Unique, GoldRing (yes), discrete item flags (MinorItem, MajorItem, GreaterItem, Scroll, Hoard for Quest items without explicit Site Requirement), Name, Set.
  • Custom Categories: Role (Quest plus secondary roles), Prerequisite (; = OR, && = AND), Site Requirement (supports && multi-site clauses such as Bag End && Lórien), Region Requirement, Target Species, Special Ability (Gold Ring: Allow Test, Gold Ring: Exclude One Ring).

Coded Rules & Priority Tiers

  • Role (Quest (Only) vs. Hybrid Quests): Pure Quests carrying only Role: Quest match Quest (Only); Quests carrying additional Role tags match if any of those secondary roles is checked.
  • Eligibility Guards: Enforces Region Requirement, Site Requirement (all terms in && clauses must exist in Sites), Specific, Skill/Race, and Target Species (e.g., Dúnadan on Andúril, the Flame of the West, Hobbit on Red Book of Westmarch).
  • 2-Tier Prerequisite Resolution: Checks all Prerequisite options (and anything those cards require) for eligibility, selecting the valid option needing the fewest new cards:
    1. Tier 1 (Already Satisfied): Quests whose Prerequisite is already in the deck (0 extra cards needed).
    2. Tier 2 (Standalone / Self-Contained): Quests with no Prerequisite, or Quests whose missing prerequisite cards pass all guards and fit in remaining section capacity (auto-drafted into the same section).
  • Optional One Ring Package (Auto-draft One Ring package): When checked and a Quest requires The One Ring (Cracks of Doom, Gollum's Fate) that is not yet in the deck, checks for a GoldRing = yes site in Sites and automatically bundles The One Ring, an optimal Gold Ring (if missing), and an unrestricted Gold Ring: Allow Test card (excluding Gold Ring: Exclude One Ring, and accounting for prior Special Rings consuming single-use Short-event testers).
  • Per-Cycle Site-Capacity Matching: Prefers quests (including Quest Items and any site-tapping Prerequisite cards such as factions or an auto-drafted Gold Ring) that fit within Decks Before Council tap capacity across non-haven sites in Sites (1 Resources play per cycle; havens unlimited). If none fit within remaining capacity, it still drafts an eligible quest and logs a ⚠ warning.

10. Resource Events

Pipeline Step: Step 10 • Target Sections: Resources • Sideboard • Card Scope: Resource (Events & Twilight)

Drafts requested environment cards (Gates of Morning and Twilight), then auto-fills all remaining Play Deck capacity up to Play Deck Size (plus requested Additional Events in Sideboard) across checked Role tags.

Attributes & Categories Read

  • Official Attributes: Primary (Resource), Secondary (Short-event, Long-event, Permanent-event), Alignment (Hero, Neutral, Dual, or blank), Skill, Specific, Unique, Name (Gates of Morning, Twilight), Set.
  • Custom Categories: Role (filtered by Role), Special Ability (excludes Gold Ring: Allow Test and Palantír: Allow Use), Site Requirement, Region Requirement, Prerequisite, Target Species.

Exclusions & Coded Rules

  • Reserved Exclusions: Excludes Gates of Morning, Twilight, Role = Quest events, Role = Faction Support events, Gold Ring: Allow Test events, and Palantír: Allow Use events from the general auto-fill pool so earlier tabs and the environment spinners remain authoritative.
  • Environment Cards First: Drafts requested Gates of Morning (≤ 3) and Twilight (preferring Neutral printing; ≤ 3 combined across the entire deck) before auto-fill runs.
  • Proportionate Role Allocation: Computes eligible events passing all guards (Role, Region Requirement, Site Requirement, Specific, existing Prerequisite in Pool + Resources + Sideboard, Skill/Race, and Target Species). Allocates slots proportionately to the number of eligible cards in each checked Role (guaranteeing at least 1 per eligible role when enough slots exist), drafting narrowest roles first with variety-first copy selection.

11. Creatures

Pipeline Step: Step 11 • Target Sections: Hazards • Sideboard • Card Scope: Nazgûl • Nazgûl Support • Standard & Dual-Mode Creatures

Drafts Hazard creatures and Nazgûl packages while tracking tournament creature equivalents (Standard + (Nazgûl + Dual) / 2 >= 12) and adapting keying rules to the global Tailor Hazards to current deck toggle.

Attributes & Categories Read

  • Official Attributes: Primary (Hazard), Secondary (Creature, Creature/Permanent-event, Creature/Short-event, and events for Nazgûl Support), Alignment (Hero, Neutral, Dual, or blank), Race (Nazgûl and checked items in Creature Race), Unique, Name, Set.
  • Custom Categories: Target Species (Nazgûl for Nazgûl Support), Region Requirement, Site Requirement, Region Type.

Draft Order & Proportionate Species Bucketing

  • Execution Order (Hazards before Sideboard):
    1. Nazgûl (0.5 equiv): Race = Nazgûl (≤ 9 combined). In Target Current Deck mode, prioritizes creature-keyable Nazgûl over permanent-event-only Nazgûl.
    2. Nazgûl Support: Non-Nazgûl Hazard events carrying Target Species: Nazgûl.
    3. Standard Creatures (1.0 equiv): Secondary (Creature), distributed proportionately across checked Creature Race buckets with variety-first sampling.
    4. Dual-Mode Half (0.5 equiv): Non-Nazgûl cards whose Secondary contains both Creature and event (such as Shelob or Mouth of Sauron), also bucketed proportionately by checked species.

Targeting Mode Behavior (Controlled on General Settings)

Check Aspect Unknown Opponent Mode (Unchecked) Target Current Deck Mode (Checked)
Keying Filters UI Enabled: Uses checked Region Terrains and Site Holds on the Creatures tab. Disabled: Manual Keying Filters are ignored; reads your drafted Sites deck directly.
Region & Site Keying Creature passes if it is unkeyed, or if any Region Requirement matches a checked terrain (directly or via its Region card's Region Type), or any Site Requirement matches a checked hold (directly or via its Site card's Site hold). Creature passes only if at least one Region Requirement or Site Requirement tag matches a drafted region, Region Type, or site/haven in Sites.

Warnings

  • ⚠ Warns if Nazgûl Support is drafted with 0 Nazgûl in Hazards + Sideboard, or if Hazards creature equivalents fall below 12.

12. Hazard Events

Pipeline Step: Step 12 • Target Sections: Hazards • Sideboard • Card Scope: Hazard (Events & Twilight)

Drafts requested Hazard environment cards (Doors of Night and Twilight), then auto-fills remaining Play Deck capacity up to Play Deck Size (plus requested Additional Events in Sideboard) across checked Role tags.

Attributes & Categories Read

  • Official Attributes: Primary (Hazard), Secondary (Short-event, Long-event, Permanent-event; checks Long-event for Duration), Alignment (Hero, Neutral, Dual, or blank), Specific, Unique, Name (Doors of Night, Twilight), Set.
  • Custom Categories: Role (filtered by Role), Region Requirement, Site Requirement, Target Item, Target Species, Prerequisite, Automatic Attack, Region Type.

Exclusions & Coded Rules

  • Reserved Exclusions: Excludes Doors of Night, Twilight, and all cards belonging to Step 11 (Creatures tab: Nazgûl, Nazgûl Support, Standard Creatures, and Dual-Mode Half-Creatures).
  • Shared Twilight Cap: Drafts Doors of Night (≤ 3) and Twilight first; Twilight strictly shares a single 3-copy limit across Resources + Hazards + Sideboard.
  • Proportionate Role Auto-Fill & Duration Gate: Distributes remaining Hazards and Sideboard event slots proportionately across checked Role buckets with variety-first sampling.
