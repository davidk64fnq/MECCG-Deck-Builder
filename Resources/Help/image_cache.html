Card Artwork Cache & Downloader

Card Artwork Cache System

The application employs a high-performance two-tier caching architecture designed to run reliably in restricted environments (such as C:\Program Files):

  1. Memory Cache: An in-memory cache holding up to 10,000 active Bitmaps for instant display when clicking or navigating.
  2. Local Disk Cache: Checks for card images in the user storage cache under %LOCALAPPDATA%\MECCG Deck Builder\Images\{Set}\ (or local subfolders in portable mode).
    • If found locally in user storage or in pre-bundled application set folders, the image loads immediately with zero network latency.
    • If missing, it downloads asynchronously from Cardnum, saves a copy to disk in user storage, and loads it into memory.

Batch Image Downloader

To pre-cache card artwork for tournament or offline use:

  1. Enable all sets you want cached in the Set menu.
  2. Reset filters (Ctrl+R) so all cards appear in the Master List.
  3. Select Tools > Download Images.
Background Download: The batch downloader runs asynchronously with real-time progress reported in the window title bar, keeping the application responsive.

Offline Architecture & Database Upgrades

  • Curated Local Database: The application starts immediately using the local curated card (cards-dc.json) and set (sets-dc.json) definitions with zero startup network calls.
  • Portable Mode: Placing an empty file named portable.flag next to MECCG Deck Builder.exe directs all images, data files, and user settings to stay inside the application folder rather than using %LOCALAPPDATA%.
