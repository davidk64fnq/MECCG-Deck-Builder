Card Artwork Cache & Downloader

Card Artwork Cache System

The application employs a high-performance two-tier caching architecture:

  1. Memory Cache: An in-memory cache holding up to 10,000 active Bitmaps for instant display when clicking or navigating.
  2. Local Disk Cache: Checks for card images on disk under local set folders (e.g., METW/metw_adrazar.jpg).
    • If found locally, the image loads immediately with zero network latency.
    • If missing, it downloads asynchronously from Cardnum, saves a copy to disk, and loads it into memory.

Batch Image Downloader

To pre-cache card artwork for tournament or offline use:

  1. Enable all sets you want cached in the Set menu.
  2. Reset filters (Ctrl+R) so all cards appear in the Master List.
  3. Select Tools > Download Images.
Background Download: The batch downloader runs asynchronously with real-time progress reported in the window title bar, keeping the application responsive.

Offline Data Fallbacks

  • Cards: Automatically attempts to download the latest card definitions from Cardnum on launch, falling back to local cards-dc.json if offline.
  • Sets: Attempts to download set metadata on launch, falling back to local sets-dc.json if offline.
