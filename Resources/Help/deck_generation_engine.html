Procedural Deck Generation Engine

MECCG Deck Builder features an automated generation engine that builds legal, randomized decks from declarative JSON rule templates (via Tools > Generate Deck from Rules... or F5).

Core Generation Mechanics

  • Symmetric Filtering: Rules can query official card attributes (Primary, Race, Skill, Name) and custom user taxonomy tags (Faction Focus, Home Region).
  • Strict Legality & Copy Limits: Automatically enforces game limits: maximum 1 copy for unique cards and maximum 3 copies for non-unique cards across the entire deck.
  • Tiered Variety-First Distribution: To maximize card variety, the engine exhausts all 0-copy (unused) cards before assigning 2nd copies, and all 2-copy cards before assigning 3rd copies.
  • Branching Archetypes (RandomChoice): Author multiple company archetypes or hazard strategies in a single file with weighted random selection and dynamic title overrides.
  • Instant Re-Run (F5): Press F5 (Tools > Re-run Deck Rules) to immediately re-run the last used rules file directly from disk without re-opening file dialogs.
