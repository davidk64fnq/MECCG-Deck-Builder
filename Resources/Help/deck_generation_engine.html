Procedural Deck Generation Engine

MECCG Deck Builder features an automated generation engine that builds legal, randomized decks from declarative JSON rule templates (via Deck > Generate from Rules... [Ctrl+G] or F5).

Core Generation Mechanics

  • Unified Attribute & Tag Querying: Rules can combine any official card attributes (Attributes) and custom user categories (Categories). All criteria must match, with semicolon OR support inside any field and universal wildcard matching (* and All).
  • Relational Stat Thresholds: Query numeric attributes using comparison operators (>, >=, <, <=, !=) and ranges (e.g. "Mind": ">= 3; <= 5").
  • Blank / Drawback-Free Filtering: Seek cards with unpopulated fields using "[Blank]" (e.g. "Corruption": "[Blank]" for safe items).
  • Configurable Distribution Strategies (Distribution): Choose how card copies are sampled:
    • "Variety" (default): Prioritizes 1 copy of every eligible card title before drawing duplicate copies.
    • "Focused" (or "Playset"): Concentrates additions into full legal playsets up to 3 copies for non-unique cards and Avatars, 1 for other unique cards) of each chosen title for competitive engine consistency.
    • "Uniform" (or "Random"): Unweighted random draw with replacement up to legal deck limits.
  • Deck Copy Limits: Automatically enforces standard card copy limits: maximum 1 copy for unique cards and up to 3 copies for non-unique cards across the entire deck (with the official Avatar exception allowing up to 3 copies of one Wizard/Ringwraith, or 2 of one and 1 of another in Resources).
  • Randomized Thematic Branches (RandomChoice): Author multiple company themes or hazard packages in a single template, using weighted probability to randomly choose a theme and assign a tailored deck title.
  • Leader & Variable Capture (SaveAs & {...}): Capture chosen characters into named variables (e.g. "SaveAs": "Leader") and query their attributes (e.g. {Leader.Home}) or categories (e.g. {Leader.Category:Faction Bonus}) in subsequent rules.
  • Automated Shortfall Backups (Fallback): Attach secondary backup rules that execute automatically if a primary query yields fewer cards than requested due to uniqueness limits or missing tags.
  • Instant Re-Run (F5): Press F5 (Deck > Re-run Deck Rules) to immediately re-generate fresh randomized variations directly from disk without re-opening file dialogs.
  • Dynamic Attribute Predicate Selectors (Attribute=Value): Query dynamic criteria (e.g. Site=Haven, Site=Dark-hold, Site=Ruins & Lairs, Region=Udûn, Alignment=Neutral) directly in custom tags or rule queries, with automatic diacritic resilience and hold-type normalization.

Modular Deck Assembly Workbench (Ctrl+M)

In addition to running monolithic generation templates, the application features an interactive Modular Deck Assembly Workbench (via Deck > Assemble from Components... [Ctrl+M]). This allows you to combine decoupled, reusable components (e.g., Company packages and Geographic Theater routes) without editing raw JSON files:

  • Multi-Directional Assembly Drivers:
    • Leader-First (Company → Theater): The starting company drafts a leader and retinue; the theater automatically expands around the leader's home territory using Haven: "Auto".
    • Region-First (Theater → Company): The theater establishes a geographic cluster and exports {Theater.Region}; the company drafts leaders and companions native to that theater.
  • Parametric Overrides: Refine rules at runtime without modifying files:
    • Company Slot: Multi-select species checklist (Dwarf, Elf, Dúnadan, Hobbit, Man), leader skill focus (Diplomat, Sage, Ranger, Scout, Warrior), and pool size spinner.
    • Theater Slot: Haven anchor snapping, movement mode (Starter + Region vs. Starter Only), region count, site density, terrain checklists, site hold checklists, and overland pathing toggles.
  • Dynamic Mode Synchronization: Selecting Starter Only locks region count to 0 and disables overland routes, ensuring site decks stay free of region cards.
  • Context-Aware Instant Re-Run (F5): Pressing F5 re-reads component JSON files from disk and generates fresh randomized rolls using your exact parameter choices.
  • In-Session State Recall: The workbench automatically remembers all your selections, numeric counts, and checked boxes upon reopening.
