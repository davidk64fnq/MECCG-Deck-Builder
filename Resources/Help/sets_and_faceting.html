Sets & Smart Filtering

Managing Expansion Sets

Click the Catalog menu in the top bar to choose which expansions are active in the Master List:

  • Select All Expansions: Enables all official sets and Dreamcard expansions.
  • Clear All Expansions: Deselects all expansions.
  • Individual Sets: Check or uncheck individual expansions (e.g., The Wizards, The Dragons, Dark Minions, The Lidless Eye, The Balrog, or Dreamcard sets).
Session Persistence: Your active set selection is automatically saved to user_settings.json and restored whenever the application is reopened.

Smart Cascading Filters & Automatic Conflict Resolution

The filter engine uses intelligent cascading logic to ensure you only browse relevant options:

  • Static Keys (Attribute & Category): The upper dropdowns always display all available attributes (Slots 1 & 2) and all taxonomy categories (Slots 3 & 4) across the entire catalog, regardless of which expansion sets are currently checked.
  • Dynamic Value & Tag Pruning: The lower dropdowns (Value and Tag) automatically prune their lists in real time. They only show values and tags present on cards that satisfy your active expansion sets and the criteria in all other active filter slots.
  • Auditing Unset Attributes & Untagged Cards ([Blank]): Whenever candidate cards matching your active expansions lack a value for the selected attribute or custom category, a [Blank] option dynamically appears immediately below the blank reset item. Selecting [Blank] prunes the Master List to display cards where that field is unset (such as characters without a home site or cards awaiting classification in a custom category). If all matching cards have a non-empty value, [Blank] is automatically omitted.
  • Order-Independent Narrowing: You can configure filter slots in any order. For example:
    • Enable only The Wizards (METW) in the Catalog menu.
    • In Slot 1, select Attribute: Primary. On its own, the Value dropdown lists all 5 primary card types (Character, Resource, Hazard, Site, Region).
    • In Slot 2, select Attribute: Skill. On its own, the Value dropdown lists 16 skills.
    • Now choose Value: Diplomat in Slot 2.
    • Slot 1's Value dropdown instantly prunes from 5 options down to just 2: Character and Resource, because in METW only characters and certain resource cards possess the Diplomat skill.
  • Automatic Conflict Resolution (Set Deselection): Because dynamic pruning only offers values and tags that currently match cards, it is impossible to manually select a zero-result combination using the dropdowns. Instead, conflicts only occur when you deselect an expansion set in the Catalog menu. When a set is unchecked, the engine re-evaluates all active slots simultaneously:
    • If a currently selected Value or Tag only existed in the removed set, that slot automatically clears to blank ("") so you are not left viewing an empty list.
    • If the selection still exists in the remaining sets, it remains selected.
    • Example: With both METW and METD checked, Slot 1 set to Primary = Character, and Slot 2 set to Race = Hobbit, unchecking METW causes Slot 2 to automatically clear to blank because METD contains no Hobbit characters (whereas if Slot 2 were set to Race = Dwarf, that selection would remain intact because Dwarves also appear in METD).
