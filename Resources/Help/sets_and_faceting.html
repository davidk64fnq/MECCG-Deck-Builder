Sets & Faceted Filtering

Managing Expansion Sets

Click the Set menu in the top bar to choose which expansions are active in the Master List:

  • Select All: Enables all official sets and Dreamcard expansions.
  • Clear All: Deselects all expansions.
  • Individual Sets: Check or uncheck individual expansions (e.g., The Wizards, The Dragons, Dark Minions, The Lidless Eye, The Balrog, or Dreamcard sets).

Dual-Layer Filtering Architecture

Located beneath the main workspace, four vertical column pairs of ComboBoxes provide fine-grained catalog search:

Filter GroupBox Data Source Behavior
Left GroupBox:
Card Attributes (Official Database)
(Slots 1 & 2)		 Cardnum Database: Canonical rules statistics (Primary, Alignment, Race, Skill, Mind, Prowess). Fixed, read-only rules attributes. See Official Attributes Reference.
Right GroupBox:
Custom Tags (User Taxonomy)
(Slots 3 & 4)		 User Taxonomy: Custom categories and tags managed locally. Editable classification categories. See Custom Taxonomy & Tag Management.

Cascading Faceted Search & Conflict Resolution

  • Context-Sensitive Value Pruning: Every dropdown automatically prunes options to show only values present among cards satisfying your active expansion sets and other active filter slots, completely eliminating zero-result queries.
  • Order-Independent Narrowing: Filters can be selected in any sequence. Selecting Skill = Diplomat in Slot 2 prunes Slot 1's Secondary dropdown down to card types featuring diplomats.
  • Automatic Conflict Resolution: If an active selection becomes impossible (e.g., deselecting an expansion set), the invalid slot automatically resets to blank ("").

Clearing and Resetting Filters

Method Shortcut / Gesture Behavior
Global Reset Filter > Clear All Filters / Ctrl+R Resets all 4 filter slots to blank instantly.
Slot Context Menu Right-Click any filter ComboBox Provides options to clear that specific slot or clear all slots.
Quick Keyboard Reset Escape Resets focused filter ComboBox to blank ("").
