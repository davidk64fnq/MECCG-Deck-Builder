User Interface Walkthrough

The application interface consists of a top workflow menu bar and five main functional zones arranged from left to right:

Workflow Menu Bar

  • Deck Menu
    • File Operations: New Deck (Ctrl+N), Open Deck... (Ctrl+O), Save Deck (Ctrl+S), Save Deck As...
    • Automated Generation: Generate from Rules... (Ctrl+G), Assemble from Components... (Ctrl+M), Re-run Deck Rules / Assembly (F5)
    • Platform Export: Export Deck... (Ctrl+E)
    • Application: Exit
  • Catalog Menu
    • Expansion Selection: Select All Expansions, Clear All Expansions, active expansion checkboxes
    • Artwork Caching: Download Card Artwork...
  • Taxonomy Menu
    • Tag Management: Manage Custom Tags...
    • Rules Automation: Extract Tags with Rules...
    • CSV Pipeline: Export Taxonomy Draft (CSV)..., Import Taxonomy (CSV)...
    • Tag Set Files: Load Tag Set..., Merge Tag Set..., Save Tag Set...
    • Catalog Filter Reset: Clear All Active Filters (Ctrl+R)
  • Help Menu
    • Documentation: Help Contents (F1)
    • Application Info: About MECCG Deck Builder...

Master Card List (Left Pane)

Displays all cards matching your active expansion sets and filter criteria, sorted alphabetically.

  • Single-Click: Selects the card, renders its artwork in the preview pane, and updates the Card Taxonomy Inspector.
  • Double-Click: Appends the card to the currently active deck tab on the right.
  • Right-Click: Opens the master context menu to copy cards, inspect attributes, view tags, or assign custom tags.
  • Drag & Drop: Left-click and drag the card title onto any deck listbox.

Card Image Preview (Center-Left Pane)

Displays high-resolution card artwork downloaded on demand from cardnum.net and cached locally in set folders (e.g., METW/, MEDM/).

Errata Notice: Cards flagged with ICE errata automatically load their corrected image counterpart prefixed with ice-.

Card Taxonomy Inspector (Center-Right Pane)

Positioned directly between the card artwork and the deck partitions, this persistent inspector displays live metadata for whichever card is currently selected in the Master List or any Deck tab:

  • Card Header: Displays the selected card's printed title and 4-letter set code.
  • Live Monospace Metadata Readout: A color-coded, scrollable viewer displaying all populated official attributes (slate navy) and assigned custom taxonomy tags (deep teal). Long multi-tag lists (such as Home Region or Site Requirement) and long rules descriptions wrap cleanly with a column-aligned hanging indent so colons stay strictly aligned and text is never clipped.
  • Pinned Quick Assign Bar: A compact, non-scrolling tool docked at the bottom of the inspector:
    • Category Dropdown: Automatically synchronizes with your active bottom custom filter criteria (Slots 4, 5, or 6). Changing the category dropdown refreshes the tag list instantly.
    • Tag Dropdown: Lists all known tags for the selected category. Any tag that the currently inspected card already possesses is prefixed with a checkmark (✓).
    • + Assign: Assigns the selected tag (or multiple tags separated by semicolons) to the card. The closed dropdown immediately updates to display ✓ [Tag].
    • - Remove: Removes the selected tag from the card. If the tag field is empty or doesn't match an assigned tag, clicking this button opens a popup picker listing all tags currently on the card for instant removal.
    • New Tag...: Opens the authoring dialog, pre-seeded with the active category, to register and assign a new tag in one action.

Deck Partitions (Right Pane)

Displays the five standard MECCG deck partitions across wide, easy-to-read tabs alongside the Card Taxonomy Inspector. Clicking any card inside a deck tab immediately displays both its artwork and taxonomy in the center panes:

Tab Name Description
PoolStarting PoolCharacters, starting items, and starter resources.
ResResourcesResource events, allies, factions, and playable items.
HazHazardsCreatures, hazard events, and corruption cards.
SideSideboardReserve cards accessible during play.
SiteSitesSite cards and movement region paths.

Filter Bar (Bottom Panel)

Organized into two titled GroupBoxes providing six context-sensitive faceted filter slots:

  • Left Box — Card Attributes (Official Database): Slots 1–3 query official rules properties (Attribute above Value).
  • Right Box — Custom Tags (User Taxonomy): Slots 4–6 query your custom classification taxonomy (Category above Tag). Selecting categories or tags here automatically synchronizes the Quick Assign bar in the Card Taxonomy Inspector.

Dynamic Title Bar Summary

The window title updates automatically to reflect live deck statistics:

MECCG Deck Builder - "[Deck Title]" (Pool/Res[Characters]/Haz/Side/Site)

For example: MECCG Deck Builder - "Ring Hunter" (5/30[4]/30/20/12) indicates 5 pool cards, 30 resource cards (including 4 characters), 30 hazards, 20 sideboard cards, and 12 sites.
