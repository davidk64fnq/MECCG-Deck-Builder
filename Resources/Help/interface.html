User Interface Walkthrough

The application interface is divided into four main functional zones:

1. Master Card List (Left Pane)

The left listbox displays all available cards matching your selected sets and active filter criteria, sorted alphabetically.

  • Single-Click: Selects the card and loads its image into the central preview panel.
  • Double-Click: Immediately appends the card to the currently selected deck tab on the right.
  • Right-Click: Opens the master context menu to copy the card into a specific deck tab, inspect its Cardnum metadata, or assign custom user tags.
  • Drag & Drop: Left-click and hold to drag the card title onto any deck listbox.

2. Card Image Preview (Center Pane)

Displays a high-resolution preview of the selected card. Images are downloaded automatically from cardnum.net upon first selection and saved into a local folder named after the card set (e.g., METW/, MEDM/).

Errata Notice: Cards flagged with ICE errata automatically load their corrected image counterpart prefixed with ice-.

3. Deck Tabs (Right Pane)

The right pane features five tabbed lists representing standard MECCG deck sections:

Tab Name Description
Pool Starting Pool Characters, starting items, and starter resources.
Res Resources Resource events, allies, factions, and playable items.
Haz Hazards Creatures, hazard events, and corruption cards.
Side Sideboard Reserve cards accessible during the game.
Site Sites Site cards and region movement paths.

4. Filter Bar (Bottom Panel)

Located beneath the three main panes, four pairs of ComboBoxes allow fine-grained catalog filtering:

  • Slots 1 & 2 (Cardnum Filters): Select from official card properties (Primary type, Mind, Direct Influence, Artist, etc.).
  • Slots 3 & 4 (Custom Filters): Create, manage, and filter using user-defined classification tags.

Dynamic Title Bar Summary

The window title updates automatically to reflect deck statistics:

MECCG Deck Builder - "[Deck Title]" (Pool/Res[Characters]/Haz/Side/Site)

For example: MECCG Deck Builder - "Ring Hunter" (5/30[4]/30/20/12) indicates 5 pool cards, 30 resource cards (including 4 characters), 30 hazards, 20 sideboard cards, and 12 sites.
