Saving & Export Formats

Native Deck Files (.json)

Use File > Save or File > Open (Ctrl+O) to store and load complete deck configurations in native JSON format. This preserves:

  • The full contents of all 5 tabs (Pool, Resources, Hazards, Sideboard, Sites).
  • Active set selections.
  • Deck title.

Export Options (File > Export / Ctrl+S)

Choose File > Export to open the export dialog and select from the dropdown filter:

Format Extension Target Platform & Usage
Tabletop Simulator .json Generates five JSON deck files (one for each section: _pool.json, _resource.json, _hazard.json, _sideboard.json, _site.json) ready to be dropped into Tabletop Simulator's Saved Objects folder.
Play MECCG .play Standard export for the online Play MECCG client. Formats cards with parenthetical subtitle convention (e.g. Adrazar (TW)) using Windows-1252 ANSI encoding.
Cardnum Deck .cnum Exports deck listings using standard Cardnum code prefixes (e.g. 1 Adrazar (TW)) grouped by deck sections.
Archive Listing .archive A structured analysis format that breaks down your deck by category: Items (Minor, Major, Greater, Ring), Events (Short, Long, Permanent), Allies, Factions, Characters by race, and Sites by type.
Text File .txt A clean, human-readable plain text breakdown of all deck sections with section headers.
