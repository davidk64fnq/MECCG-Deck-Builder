Worked Example: Dynamic Faction Recruitment

This end-to-end tutorial demonstrates how to build context-aware procedural deck generation templates using branching company themes, variable capture, dynamic placeholders, and automated shortfall fallbacks.

1. The Goal: Context-Aware Company Themes

In MECCG, leaders often possess direct influence (DI) bonuses against specific factions (for example, Thranduil receives +2 DI against the Wood-elves, and Dáin II receives +2 DI against the Iron Hill Dwarves).

We want to create an automated deck rule template that:

  1. Randomly selects a company theme (e.g. Dwarf Company vs. Elf Company).
  2. Selects an appropriate starting diplomat leader for that company and captures them into an in-memory variable ("SaveAs": "Leader").
  3. Dynamically recruits the specific faction our leader specializes in influencing by matching the card's title to the leader's tagged bonus ("Name": "{Leader.Category:Faction Bonus}").
  4. Gracefully falls back: If the randomly chosen leader has no specific faction bonus (e.g. Balin), the generator must detect the shortfall and automatically fall back to recruiting any faction matching that leader's race ("Race": "{Leader.Race}").
Tag Availability Notice: Character recruiting bonuses are pre-cataloged in the baseline taxonomy file (Rules_Support_Tags.json) loaded automatically on launch. If you want to learn how to scan card text and create these tags yourself, see Taxonomy Extraction Tools: Extracting Faction Bonuses.

Template Mechanics Walkthrough:
  • Randomized Thematic Branches (RandomChoice): Evaluates a weighted random choice between Dwarf and Elf companies, applying the selected branch's rules and updating the deck title dynamically.
  • Variable Capture ("SaveAs": "Leader"): Captures whichever diplomat is randomly selected into an execution context for downstream rules.
  • Querying Card Titles ("Name": "{Leader.Category:Faction Bonus}"): Queries published faction cards by title using the captured leader's assigned category tag.
  • Automated Shortfall Fallbacks (Fallback): If the captured leader has no bonus tag, the query returns 0 cards; the engine detects the shortfall and immediately executes the fallback rule for the remaining count (recruiting a faction by {Leader.Race}).

3. Running and Verifying the Deck

  1. Click Deck > Generate from Rules... (Ctrl+G) and select Hero_Faction_Rules.json.
  2. Review the generation summary dialog to observe context-aware recruitment:
    • Scenario A (Leader has Tag): If the engine samples Dáin II, the primary rule resolves Name: Iron Hill Dwarves and adds it directly to Resources.
    • Scenario B (Leader has no Tag): If the engine samples a leader without a bonus tag (such as Balin), the primary rule resolves to blank, adds 0 cards, and immediately hands off to the Fallback rule. The fallback resolves Race: Dwarf and recruits a generic faction (such as Blue Mountain Dwarves).
  3. Press F5 (Deck > Re-run Deck Rules) to instantly re-execute the file and generate new randomized variations.
