Worked Example: Dynamic Faction Recruitment

This end-to-end tutorial demonstrates how to build context-aware procedural deck generation templates using branching company themes, variable capture, dynamic placeholders, signature character queries, and automated shortfall fallbacks.

1. The Goal: Context-Aware Company Themes

In MECCG, leaders often possess direct influence (DI) bonuses against specific factions (for example, Thranduil receives +2 DI against the Wood-elves, and Dáin II receives +2 DI against the Iron Hill Dwarves).

We want to create an automated deck rule template that:

  1. Randomly selects a company theme (Dwarf Company, Elf Company, or Dúnadan Company).
  2. Selects an appropriate starting diplomat leader for that company and captures them into an in-memory variable ("SaveAs": "Leader").
  3. Dynamically recruits the specific faction our leader specializes in influencing by matching the card's title to the leader's tagged bonus ("Name": "{Leader.Category:Faction Bonus}").
  4. Gracefully falls back: If the randomly chosen leader has no specific faction bonus (e.g. Balin), the generator automatically falls back to recruiting any faction matching that leader's race ("Race": "{Leader.Race}").
  5. Drafts character-specific signature cards: Dynamically recruits cards tied to the leader using the official Specific attribute (e.g. Return of the King for Aragorn II), while safeguarding generic item queries with "Specific": "[Blank]".
  6. Ensures a legal starting site: Automatically resolves the leader's origin using "Name": "{Leader.Home}".
Tag Availability Notice: Character recruiting bonuses are pre-cataloged in the baseline taxonomy file (Rules_Support_Tags.json) loaded automatically on launch. If you want to learn how to scan card text and create these tags yourself, see Taxonomy Extraction Tools: Extracting Faction Bonuses.

Template Mechanics Walkthrough:
  • Randomized Thematic Branches (RandomChoice): Evaluates a weighted random choice among Dwarf, Elf, and Dúnadan companies, updating the deck title dynamically.
  • Variable Capture ("SaveAs": "Leader"): Captures whichever diplomat is sampled into an execution context for downstream queries.
  • Querying Card Titles ("Name": "{Leader.Category:Faction Bonus}"): Queries published faction cards by title using the captured leader's assigned category tag.
  • Dynamic Signature Recruitment ("Specific": "{Leader.Name}"): If Aragorn II is selected as the Dúnadan leader, the rule automatically drafts Return of the King. If the leader has no signature cards, the shortfall fallback drafts a general influence resource instead.
  • Blank Filtering ("Specific": "[Blank]"): Prevents non-matching companies from accidentally drawing signature cards in open item queries.
  • Universal Starting Site ("Name": "{Leader.Home}"): Evaluates the leader's home (whether a fixed haven or dynamic predicate) to guarantee the starting site is in the deck.

3. Running and Verifying the Deck

  1. Click Deck > Generate from Rules... (Ctrl+G) and select Hero_Faction_Rules.json.
  2. Review the generation summary dialog to observe context-aware recruitment:
    • Scenario A (Leader has Specific Tag): If the engine samples Dáin II, the primary rule resolves Name: Iron Hill Dwarves and adds it directly to Resources.
    • Scenario B (Leader has Universal Bonus / Wildcard): If the engine chooses the Dúnadan company and samples a universal diplomat like Adrazar, the token resolves to Name: All. The generator recognizes All as a wildcard and selects a random faction from any faction present in your active expansions.
    • Scenario C (Leader has no Tag): If the engine samples a leader without a bonus tag (such as Balin), the primary rule resolves to blank, adds 0 cards, and immediately hands off to the Fallback rule. The fallback resolves Race: Dwarf and recruits a generic faction (such as Blue Mountain Dwarves).
    • Scenario D (Leader has Signature Card): If the engine chooses the Dúnadan company and rolls Aragorn II, Specific: {Leader.Name} matches and drafts Return of the King into Resources, alongside his starting site Rivendell (via {Leader.Home}).
  3. Press F5 (Deck > Re-run Deck Rules) to instantly re-execute the file and generate new randomized variations.
