CSV Spreadsheet Pipeline

MECCG Deck Builder features a two-way CSV spreadsheet pipeline via the Taxonomy menu (Export Taxonomy Draft (CSV)... and Import Taxonomy (CSV)...). This allows you to audit card taxonomy across hundreds of cards at a glance, bulk-assign tags in Microsoft Excel or Google Sheets, and perform multi-category edits in a single import.

1. Dynamic Spreadsheet Column Layout

When you select Taxonomy > Export Taxonomy Draft (CSV)..., the export automatically configures its columns based on your active filter slots:

Column Header Role / Type Description & Behavior
Card Name Required The exact printed title of the card (e.g. Anborn, Adrazar). Matches cards in the catalog.
Set Required The 4-letter expansion code (e.g. METW, MEDM, MEAS). Disambiguates reprints across expansions.
[Active Official Attributes] Reference (Read-Only) Any official rules attributes selected in Slots 1 & 2 (e.g. Race, Skill, Alignment). Populated with each card's official data. Defaults to Primary if no attributes are selected.
Import Safety: All official Cardnum attributes are automatically recognized and skipped during import, ensuring they never become custom tags.
[Custom Category Columns] Editable (Custom Tags) Any custom categories selected in Slots 3 & 4 (e.g. Faction Focus, Combat Role). Exports pre-populated with all tags currently assigned to each card. If no custom category is selected in the filter slots, an [Insert Category Name] template column is generated instead.
Card Text Reference (Read-Only) Full printed rules text for reference while editing. Automatically skipped during import.
Multi-Tagging Syntax: To assign multiple tags within the same category column, separate them with a semicolon (;), for example: Dwarf Factions; All Factions or Scout Support; Ranger Buffer.

2. Authoritative "Edit & Replace" Import Behavior

When you select Taxonomy > Import Taxonomy (CSV)..., the importer treats the spreadsheet as the authoritative record for every custom category column included in the file:

  • Multiple Columns Processed Simultaneously: You can add as many custom category columns side-by-side as you like (e.g. Faction Focus, Role, Hazard Package, Deck Priority). The importer evaluates every custom column for every card in the spreadsheet.
  • Full Edit & Replace (Not Append): If a card already possesses tags in a category, the import replaces them with the exact contents of the cell. If you change Scout Support to Warrior Tank, the old tag is removed and the new tag is assigned.
  • Clearing & Deleting Tags: Emptying a cell (or typing [clear], [none], or -) completely removes that category's tags from that card.
  • Column Scope Isolation: Only the custom categories present as headers in the CSV are updated. Any categories not in the spreadsheet remain completely untouched.
  • Card Scope Isolation: The import only updates the specific cards listed in the CSV. Any cards from your catalog omitted from the file retain their existing tags.
  • Placeholder Protection: Unmodified template headers (like [Insert Category Name]) and instructional cell hints (like [Insert tag...]) are automatically detected and ignored.

3. Step-by-Step Workflow

Scenario A: Auditing & Editing Existing Tags

  1. In the main window, choose the expansion sets you want to audit in the Catalog menu.
  2. In Slot 3 (bottom panel), select the category you want to inspect (e.g. Category: Faction Focus).
  3. Select Taxonomy > Export Taxonomy Draft (CSV)... and save the file.
  4. Open the CSV in Excel or Google Sheets. The Faction Focus column is already filled with all current tags. You can glance down the column, correct typos, delete tags, or add second tags with a semicolon (;).
  5. Save the spreadsheet as a CSV file.
  6. In MECCG Deck Builder, select Taxonomy > Import Taxonomy (CSV)... and select your edited file. Your catalog is updated instantly.

Scenario B: Drafting Brand New Categories from Scratch

  1. Filter the Master List to the cards you want to classify (for example, set Slot 1 to Primary = Character).
  2. Select Taxonomy > Export Taxonomy Draft (CSV)....
  3. Open the file in your spreadsheet editor. Replace the header [Insert Category Name] with your desired category name (e.g. Combat Role).
  4. (Optional) Add additional custom category columns next to it (e.g. Expedition Priority).
  5. Enter tags for each card and save as CSV.
  6. Select Taxonomy > Import Taxonomy (CSV).... All new categories and tags are immediately registered in the application.
