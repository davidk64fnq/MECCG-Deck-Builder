CSV Spreadsheet Pipeline

To facilitate large-scale taxonomy authoring or collaborative review in Google Sheets or Microsoft Excel, MECCG Deck Builder supports round-trip CSV draft exporting and importing via the Tools menu.

Spreadsheet Column Layout

Column Header Required? Description & Behavior
Card NameRequiredExact card title (e.g. Anborn, Adrazar). Matches cards in catalog.
SetRequiredExpansion code (e.g. METW, MEDM) used to disambiguate reprint cards.
PrimaryOptionalOfficial primary type (e.g. Character). Read-only; ignored during import.
[Custom Category Columns]OptionalAny header (e.g. Faction Focus, Role) becomes a custom category. Cell contents are imported as tags.
Card TextOptionalFull rules text provided for reference during editing. Ignored during import.
Multi-Tagging Syntax: To assign multiple tags within the same category to a card, separate them with a semicolon (;), for example: Dwarf Factions; All Factions or Scout Support; Ranger Buffer.

Step-by-Step Workflow

  1. Scope the Master List: Select your desired expansion sets and set filter criteria so that only target cards appear in the Master List.
  2. Export Draft: Select Tools > Export Taxonomy Draft (CSV)....
  3. Edit in Excel / Google Sheets: Add custom category headers, enter tags into cells, and download as a CSV file.
  4. Import to Deck Builder: Select Tools > Import Taxonomy from CSV.... Categories and tags immediately populate filter dropdowns and card context menus.
