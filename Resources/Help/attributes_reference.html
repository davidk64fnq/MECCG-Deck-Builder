Official Card Attributes Reference

Every card in the catalog carries official rules attributes synchronized from the Cardnum open database. These keys can be filtered via UI Slots 1 & 2, queried in procedural deck rules, or inspected in the right-click Card Attributes monospace view.

1. Core Identifiers & Metadata

Key Type Example Values Notes
Name string "Wood-elves", "Rivendell", "Glamdring" Exact English card title. Queryable in deck generation rules and cross-card token lookups.
Set string "METW", "MEDM", "MELE", "MEBA" Canonical 4-letter expansion set code.
FullCode string "Wood-elves (TW)", "Adrazar (LE)" Set-disambiguated title used by Cardnum and Play MECCG.
Text string Rules text printed on the face of the card. Evaluated by automated taxonomy regex harvesting.

3. Character & Creature Statistics

Key Values & Lore Normalization
Race Dúnadan, Dwarf, Elf, Hobbit, Man, Wizard, Orc, Troll, Dragon, etc.
Note: Lore sub-races are canonically normalized to Elf and Dwarf for clean queries.
Subrace Preserves original Tolkien sub-races: Silvan Elf, Noldo Elf, Longbeard Dwarf, etc.
Skill Warrior, Scout, Ranger, Sage, Diplomat. Compound skills (e.g. Warrior/Scout) are indexed individually.
Mind, Direct, Prowess, Body, Corruption, MPs Numeric gameplay stats and victory points.
Home Designated home sites for characters (e.g. "Rivendell", "Bree").

4. Sites & Movement

Key Values
Site Free-hold, Border-hold, Ruins & Lairs, Shadow-hold, Dark-hold, Haven
Region Geographic territory (e.g. Arthedain, Rhudaur, Gorgoroth).
Playable, Hoard, Haven Site item-playability flags and nearest haven designations.
