Saving Native Decks (.json)

Native Save Files (.json)

Use File > Save (Ctrl+S) or File > Open (Ctrl+O) to store and load complete deck configurations in native JSON format.

What is Preserved

  • Deck Title: Derived from the saved file name or procedural template title.
  • Active Expansion Sets: The exact selection of sets used when building the deck.
  • Section Contents: The complete card contents across all 5 deck partitions (Pool, Resources, Hazards, Sideboard, Sites).

Save File JSON Structure

Native deck save files store an assembled deck instance using simple card records [Name, ImageName, Set, Id]: 

{
  "CurrentDeckTitle": "Ring Hunter",
  "SetList": [ "METW", "MEDM" ],
  "PoolList": [
    [ "Adrazar", "metw_adrazar.jpg", "METW", "0" ]
  ],
  "ResourceList": [],
  "HazardList": [],
  "SideboardList": [],
  "SiteList": []
}
Rule Templates vs. Save Files: Native deck files represent saved decks. If you want to author generative rule files that create randomized decks from queries, see Deck Rules JSON Schema Reference.
