Deck Building Operations

Adding Cards

  • Fastest Method: Switch to your desired deck tab on the right, find the card in the Master List, and double-click it.
  • Drag and Drop: Left-click and drag the card from the Master List onto any visible tab list.
  • Targeted Right-Click: Right-click a card in the Master List, open the Copy submenu, and pick the destination tab (Pool, Resources, Hazards, Sideboard, Sites). This automatically switches focus to that tab.

Duplicating Cards

To add another copy of a card already in a deck tab, simply double-click it directly within that tab's list.

Moving Cards Between Tabs

  1. Right-click the card inside any deck tab.
  2. Highlight Move.
  3. Select the destination tab. The card is added to the target tab and removed from the current tab.

Deleting Cards

  • Right-click the card in the deck tab and select Delete.

Context Menu Reference (Deck Tabs)

Menu Item Action
[Card Name Header] Shows card title in the active header color.
Copy Duplicates card to Pool, Resources, Hazards, Sideboard, or Sites.
Move Transfers card to another tab and removes it from current tab.
Delete Permanently removes this copy from the current tab.
Cardnum Filters Displays a monospace readout of all official database attributes for this card.
Custom Filters Shows user-defined tags currently assigned to this card.
