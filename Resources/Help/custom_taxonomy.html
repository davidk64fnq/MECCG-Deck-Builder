Custom Taxonomy & Tag Management

MECCG Deck Builder allows you to classify cards using your own customizable taxonomy system (for example, Strategy → Ring Destruction or Role → Scout Support).

1. Tagging Cards & Quick Authoring

You can assign, toggle, or author custom tags directly on any card in the Master List or active deck tabs without disturbing your filter dropdowns:

  • Assign or Toggle a Tag: Right-click a card and navigate to Assign Tag > [Category] > [Tag]. Currently assigned tags display a checkmark (✓). Clicking an already-assigned tag toggles it off.
  • Author a New Tag on the Fly: Right-click a card and select Assign Tag > [+ Author New Tag...]. This opens a quick prompt where you can select or type a category and tag in one action, immediately registering it in your catalog.
  • Add Tag to Existing Category: Under Assign Tag > [Category], click + Add Tag... to append a new tag value directly into that specific category.
  • Granular Removal: The right-click Remove Tag submenu displays each tag currently assigned to that card, allowing you to remove individual tags without clearing the entire category.
Multi-Tagging: Cards can hold multiple tags within the same category. For example, a multi-role character can hold both Scout Support and Ranger Buffer under the Role category.

2. Taxonomy Manager (Taxonomy > Manage Custom Tags...)

For centralized catalog-wide organization, select Taxonomy > Manage Custom Tags... to open the management dialog:

  • Add Categories: Create new classification categories (e.g. Deck Theme, Hazard Strategy, Role).
  • Add Tags: Add predefined tag values under any selected category so they appear in dropdown filters and context menus.
  • Rename Categories or Tags: Rename terms across your taxonomy; all tagged cards in the catalog are updated automatically.
  • Delete Categories or Tags: Safely remove terms from the database and strip them from all tagged cards.

3. Saving, Loading & Merging Custom Tag Sets

The application differentiates between source files (read-only files pulled into memory) and destination files (files written to disk):

Menu Action File Role Behavior in Active Session (Memory) Effect on Disk
Taxonomy > Load Tag Set... Source Wipe & Replace: Clears all active categories and tags in memory, then loads the selected file fresh. Read-only (file on disk is not modified).
Taxonomy > Merge Tag Set... Source Append & Combine: Reads the selected file and folds its categories and tags into your active memory without erasing what is already open. Read-only (file on disk is not modified).
Taxonomy > Save Tag Set... Destination None (active taxonomy in memory remains unchanged). Write / Export: Serializes all categories and tag assignments currently in memory out to the chosen .json file.
Automatic Baseline Loading: On launch, the application automatically loads Rules_Support_Tags.json (if present in the program folder) as the baseline taxonomy into memory. Because memory is already populated on launch, you never need to load or merge this baseline file manually.

Where to Store Your Tags: Baseline vs. Modular Files

When you author or extract custom tags, choose your storage location based on how you want to use them:

  • Auto-Loaded Baseline: If you want your new tags to be permanently available in every future session, select Taxonomy > Save Tag Set..., select Rules_Support_Tags.json, and confirm overwrite.
  • Modular Strategy Files: If you are creating project-specific tags (such as a private tournament hazard package), save them under a distinct filename (e.g. Hazard_Packages.json). You can merge this file into any session on demand using Taxonomy > Merge Tag Set....

Understanding "Merge Tag Set..." (Worked Example)

Suppose you receive a specialized tag set from another player called Hazard_Packages.json (which tags cards with custom labels like Hazard Strategy: Nazgûl Rush):

  • If you used "Load Tag Set...": The program would wipe out your baseline rules tags (Resolved Site, Faction Bonus) and replace them with the hazard file. The deck generator would no longer know how to resolve starting sites or recruit faction bonuses.
  • When you use "Merge Tag Set...": The program reads Hazard_Packages.json as a source. It keeps all of your existing rules tags and appends the hazard tags right alongside them. If a card already has tags in a category, new tags are safely appended with a semicolon separator (e.g., Orcs; Trolls).
