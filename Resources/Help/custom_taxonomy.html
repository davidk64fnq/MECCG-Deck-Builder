Custom Taxonomy & Tag Management

MECCG Deck Builder allows you to classify cards using your own custom classification system (e.g., Archetype → Ring Destruction or Role → Scout Support).

1. Taxonomy Manager (Filter > Manage Custom Tags...)

Open Filter > Manage Custom Tags... to access the central management dialog:

  • Add Categories: Create new classification categories (e.g., Archetype, Hazard Package, Role).
  • Rename Categories or Tags: Rename terms across your taxonomy; all tagged cards are updated automatically.
  • Delete Categories or Tags: Safely remove terms from the database and strip them from tagged cards.

2. Tagging Cards & Multi-Tag Assignment

Cards can hold multiple tags within the same custom category:

  • Assign or Reassign Tag: Right-click a card and select Assign Tag > [Category] > [Tag]. Currently assigned tags display a checkmark (✓). Clicking a checkmarked tag toggles it off.
  • Author New Tag: Right-click a card and select Assign Tag > [+ Author New Tag...] to create and assign a new tag in one action without disturbing your filter bar.
  • Granular Removal: The Remove Tag menu displays each assigned tag individually, allowing removal without wiping the category.

3. Saving & Loading Custom Tag Sets

  • Filter > Save Tag Set...: Exports your custom taxonomy and all card assignments to a .json file.
  • Filter > Load Tag Set...: Restores a previously saved custom tag set file.
