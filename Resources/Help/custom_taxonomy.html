Custom Taxonomy & Tag Management

MECCG Deck Builder allows you to classify cards using your own custom classification system (e.g., Archetype → Ring Destruction or Role → Scout Support).

1. Taxonomy Manager (Filter > Manage Custom Tags...)

Open Filter > Manage Custom Tags... to access the central management dialog:

  • Add Categories: Create new classification categories (e.g., Archetype, Hazard Package, Role).
  • Rename Categories or Tags: Rename terms across your taxonomy; all tagged cards are updated automatically.
  • Delete Categories or Tags: Safely remove terms from the database and strip them from tagged cards.

2. Tagging Cards & Multi-Tag Assignment

Cards can hold multiple tags within the same custom category:

  • Assign or Reassign Tag: Right-click a card and select Assign Tag > [Category] > [Tag]. Currently assigned tags display a checkmark (✓). Clicking a checkmarked tag toggles it off.
  • Author New Tag: Right-click a card and select Assign Tag > [+ Author New Tag...] to create and assign a new tag in one action without disturbing your filter bar.
  • Granular Removal: The Remove Tag menu displays each assigned tag individually, allowing removal without wiping the category.

3. Saving, Loading & Merging Custom Tag Sets

The application differentiates between source files (read-only files pulled into memory) and destination files (files written to your hard drive):

Menu Action File Role Behavior in Active Session (Memory) Effect on Disk
Filter > Load Tag Set... Source Wipe & Replace: Clears all active categories and tags in memory, then loads the selected file fresh. Read-only (file on disk is not modified).
Filter > Merge Tag Set... Source Append & Combine: Reads the selected file and folds its categories and tags into your active memory without erasing what is already open. Read-only (file on disk is not modified).
Filter > Save Tag Set... Destination None (active taxonomy in memory remains unchanged). Write / Export: Serializes all categories and tag assignments currently in memory out to the chosen .json file.
Automatic Baseline Loading: On startup, the application automatically loads Rules_Support_Tags.json (if present in the program folder) as the baseline taxonomy into memory. Because memory is already populated on launch, you never need to load or merge this baseline file manually.

Understanding "Merge Tag Set..." (Worked Example)

Suppose you receive a specialized tag set from another player called Hazard_Packages.json (which tags cards with custom labels like Hazard Archetype: Nazgûl Rush):

  • If you used "Load Tag Set...": The program would wipe out your baseline rules tags (Resolved Site, Faction Bonus) and replace them with the hazard file. The deck generator would no longer know how to resolve starting sites or recruit faction bonuses.
  • When you use "Merge Tag Set...": The program reads Hazard_Packages.json as a source. It keeps all of your existing rules tags and appends the hazard tags right alongside them. If a card already has tags in a category, new tags are safely appended with a semicolon separator (e.g., Orcs; Trolls).
How to Persist Combined or Extracted Tags: Whenever you merge an external file or extract new tags using the Extraction Tools, those changes live only in your running session (active memory). To make them permanent for future application launches, select Filter > Save Tag Set..., select Rules_Support_Tags.json, and confirm overwrite.
